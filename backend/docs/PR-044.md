# PR-044: IsReply detection + omitReplies filter

## Objective

Add reply detection to the RSS parser and an `omit_replies` filter option
so users can hide reply tweets from both the feed and (eventually) push
notifications, similar to the existing retweet filter.

## Changes

### Domain
- Add `IsReply bool` field to `domain.Post`.

### Infrastructure (RSS parser)
- Detect replies in `parseRSS()`: title starts with `"@"` and is NOT a
  retweet (no `"RT @"` prefix). This matches Nitter's reply format.

### Application
- Add `OmitReplies bool` to `FeedFilter`.
- Apply in `applyFilter()`.

### HTTP adapter
- Add `omit_replies=true` query param to `SocialFeedHandler`.
- Add `IsReply` to `socialPostDTO` JSON response.

### Frontend
- Add `isReply` to `SocialPost` model + `fromJson`.
- Add `omitReplies` to `SocialAccountSettings`.
- Add "Omit replies" toggle in `_AccountSettingsSheet`.
- Add "Reply" badge in `_PostCard`.
- Send `omit_replies` query param in `HttpSocialApi`.
