## PR-045: feat(market): add regime detector and market metrics aggregator
Goal

Expose a new endpoint:

GET /api/market/regime?timeframe=4h

Response example:

{
  "timeframe": "4h",
  "regime": "compression",
  "confidence": 0.71,
  "metrics": {
    "trendBreadth": 0.18,
    "compressionBreadth": 0.34,
    "volatilityExpansion": 0.82,
    "dispersion": 0.21
  }
}

This becomes the main signal for the Market Dashboard.

Architectural improvement (completes previous tweak)

Introduce Market Metrics Aggregator.

Instead of this:

market state service
composite index service
regime detector
breadth metrics

We unify them into:

application/market/metrics

Structure:

metrics/
 ├─ composite_index_service.go
 ├─ regime_detector.go
 ├─ volatility_metric.go
 ├─ dispersion_metric.go
 └─ metrics_service.go

The aggregator computes all market-level metrics in one pass.

This avoids duplicated candle queries.

3️⃣ Volatility Expansion Metric

application/market/metrics/volatility_metric.go

Formula:

ATR_short / ATR_long

Example implementation:

func volatilityExpansion(candles []marketdata.Candle) float64 {

    if len(candles) < 30 {
        return 1
    }

    shortATR := atr(candles[len(candles)-7:])
    longATR := atr(candles[len(candles)-30:])

    if longATR == 0 {
        return 1
    }

    return shortATR / longATR
}

Interpretation:

>1.3 expansion
~1 normal
<0.8 compression
4️⃣ Dispersion Metric

Measures how differently assets move.

application/market/metrics/dispersion_metric.go

func dispersion(assetReturns []float64, marketReturn float64) float64 {

    sum := 0.0

    for _, r := range assetReturns {
        diff := r - marketReturn
        if diff < 0 {
            diff = -diff
        }

        sum += diff
    }

    return sum / float64(len(assetReturns))
}

Interpretation:

low dispersion → assets moving together
high dispersion → rotation
5️⃣ Regime Detector

application/market/metrics/regime_detector.go

func detectRegime(
    trendBreadth float64,
    compressionBreadth float64,
    volatility float64,
) (market.Regime, float64) {

    if compressionBreadth > 0.30 && volatility < 0.9 {
        return market.RegimeCompression, compressionBreadth
    }

    if trendBreadth > 0.40 && volatility > 1.0 {
        return market.RegimeTrend, trendBreadth
    }

    if volatility > 1.3 {
        return market.RegimeExpansion, volatility
    }

    return market.RegimeSideways, 0.5
}

This is intentionally simple and interpretable.

You can refine later.

6️⃣ Regime API Handler

adapters/http/market_regime_handler.go

type MarketRegimeHandler struct {
    metrics *metrics.MetricsService
}

func (h *MarketRegimeHandler) Regime(w http.ResponseWriter, r *http.Request) {

    tf := r.URL.Query().Get("timeframe")
    if tf == "" {
        tf = "4h"
    }

    regime, err := h.metrics.CalculateRegime(tf)
    if err != nil {
        http.Error(w, err.Error(), http.StatusInternalServerError)
        return
    }

    json.NewEncoder(w).Encode(regime)
}
