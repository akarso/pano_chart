## PR-067: feat(breakout): confidence-aware breakout probability engine
🎯 Objective

Make breakout probability context-aware, so it reflects:

- structure (compression strength)
- local conditions (trend health)
- global conditions (market health)
- overall reliability (confidence)
🧠 Core Principle
effective_probability = base_probability × confidence_adjustment

Where:

confidence_adjustment = (0.5 + 0.5 × confidence)
🧱 Scope
- extend breakout probability engine
- integrate confidence score
- improve notification quality
- minimal API/UI changes
1️⃣ Backend — Breakout Engine Update
File
internal/market/breakout.go
Existing (assumed)
func ComputeBreakoutProbability(baseScore float64) float64 {
    return baseScore // or some mapping
}
New version
func ComputeBreakoutProbability(baseScore float64, confidence float64) float64 {

    // Confidence scaling: keeps base meaningful but adjusts realism
    adjustment := 0.5 + 0.5*confidence

    prob := baseScore * adjustment

    return clamp(prob, 0, 1)
}
Why this formula?
Confidence	Multiplier	Effect
1.0	1.0	no change
0.5	0.75	moderate downgrade
0.0	0.5	strong downgrade

👉 Prevents:

fake high probabilities
overreaction to structure-only signals
