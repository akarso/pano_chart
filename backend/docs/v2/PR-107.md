## PR-107: Empirical transition matrix from regime history

**Layer:** application. **Depends on:** regime history (exists).

### Scope

- `BuildMatrix` / `AgeBucket` / `Blend` — consecutive transitions after
  remapping silent/indecisive → sideways and **merging adjacent equals**.
  Unknown regimes **break segments** (no fabricated cross-gap transitions).
  Laplace (+1) only on buckets with raw counts > 0.
- `Lookup` prefers an age bucket with ≥ 30 samples; otherwise a pooled
  all-age row with ≥ 30; otherwise returns the sparse row for reporting
  (`source` stays heuristic below 30).
- Blend weight / `sampleSize` / `pooled` come from the **row actually used**.
  `w = clamp(n/100, 0, 0.7)`.
- Median duration excludes the trailing open period of each segment; closed
  durations absorbed into an open continuation are kept for the median.
- `MatrixCache` — 15m TTL, per-timeframe lock, negative-cache on errors.
- HTTP: `source`, `empiricalWeight`, `sampleSize`, `pooled`; timeframe allowlisted.

### Out of scope

- Replacing the heuristic engine entirely.
- Persisting the matrix to disk.

### Tests

- 40× compression→expansion → P(expansion) ≥ 0.9 on the filled bucket.
- Empty / sparse young + rich pooled → pooled blend (not heuristic-only / not 0.25).
- silent→indecisive merge; `trend, bogus, trend` → no self-loop.
- Open tail excluded from median; empty history / n<30 → heuristic.
- Cache TTL, error negative-cache, per-TF isolation; HTTP DTO + invalid TF.
