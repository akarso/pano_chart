## PR-066: feat(setup): unified setup confidence score (multi-factor)
🎯 Objective

Introduce a single, normalized confidence score that answers:

"How much should I trust this setup right now?"
🧠 Design Principle
quality ≠ confidence
Quality → structural correctness (your current score)
Confidence → contextual validity (new layer)
🧱 Scope
- introduce confidence score (0–1)
- unify multiple signals:
  - trend health (local)
  - market health (global)
  - crowding / fragility
  - volatility conditions

3️⃣ Confidence Calculation
File
internal/setups/confidence.go
Core function
func ComputeConfidence(s SetupScore) float64 {

    var weights map[string]float64

    switch s.Regime {

    case "uptrend", "downtrend":
        weights = map[string]float64{
            "trend":     0.4,
            "market":    0.3,
            "crowding":  0.2,
            "volatility":0.1,
        }

    case "sideways":
        weights = map[string]float64{
            "trend":     0.1, // less relevant
            "market":    0.3,
            "crowding":  0.3,
            "volatility":0.3,
        }

    case "compression":
        weights = map[string]float64{
            "trend":     0.2,
            "market":    0.3,
            "crowding":  0.2,
            "volatility":0.3,
        }

    default:
        return 0.5
    }

    score :=
        weights["trend"] * s.TrendHealth +
        weights["market"] * s.MarketHealth +
        weights["crowding"] * (1.0 - s.Crowding) + // invert
        weights["volatility"] * s.VolatilityFit

    return clamp(score, 0, 1)
}

6️⃣ Sideways Setup — Answer to your question

Why

👉 This makes sideways actually usable.
