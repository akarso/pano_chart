## PR-108: Volatility seasonality per sector

**Layer:** infrastructure + application + adapters. **Depends on:** PR-098, PR-082.

### Scope

- `cmd/vol_aggregate`: `--symbols`, `--out` path **stem** (same string as
  `VOL_SECTOR_PREFIX`), `--market-symbol` (default `BTCUSDT`, must be in
  `--symbols`), optional `--sectors` / `--market-out` / `--db` / `--days`.
  Writes market-wide profile plus one equal-weight averaged file per
  configured sector that has ≥1 listed symbol via shared
  `metrics.SectorProfilePath(prefix, id)` → `{prefix}_{id}.json`
  (e.g. `--out /data/vol` and `VOL_SECTOR_PREFIX=/data/vol` →
  `/data/vol_l1.json`).
- Sector ids normalized to lowercase `[a-z0-9_-]` in `LoadSectorCatalog`
  (`metrics.NormalizeSectorID`; path separators rejected).
- `AverageFullResults`: equal-weight SpikeProb/AvgMove for **1m** minutes
  present in every contributing member; coarser intraday TFs re-derived via
  `BuildAllTimeframes`. Weekly averages among members that have weekly data;
  1d re-derived from averaged weekly. `Normalized` recomputed from AvgMove.
- `SeasonalityProvider.CurrentSpikeProbabilityFor`: sector profile when
  present; missing/corrupt → market-wide after a warn log (negative-cached
  until `ReloadSectors`). Sparse-minute spike misses keep the handler.
  Transient reload failures keep last-good; concurrent miss cannot clobber
  a successful load.
- `vol_aggregate`: skip empty early fetch windows (new listings); require
  ≥15 candles; remove stale sector files when a rerun has no members.
- Hourly reload refreshes market + sector handlers.
- `SetupService` resolves symbol sector (PR-098) and always calls `For`.
- Startup warns when catalog sectors lack profile files.

### Out of scope

- Changing `/api/volatility` to serve sector profiles.
- Weighting averages by per-bucket sample counts (not retained in JSON).

### Tests

- Path contract: write with `--out` stem, read with same `VOL_SECTOR_PREFIX`.
- `NormalizeSectorID` rejects traversal; catalog lowercases ids.
- Missing / corrupt sector JSON → market-wide (+ log); neg-cache skips
  second open.
- Sparse-minute fallback keeps cached handler (no reopen).
- `ReloadSectors` survives reload failure without hanging.
- Exclusive minutes dropped when averaging; Normalized recomputed.
- Setup Evaluate uses sector spike when mapped; unmapped → market.
