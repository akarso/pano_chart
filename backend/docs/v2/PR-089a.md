## PR-089a: feat(evaluation): evaluation store writer (compute once)

🎯 Objective

Rankings, setups, Market Pulse and notifications each fetch and score candle
windows independently. Compute each `(symbol, timeframe)` evaluation once on a
schedule, store it in Redis, and leave readers unchanged in this PR. Cheaper,
consistent, and the data source Tracks B and D need.

See ROADMAP Track A — PR-089a.

🧱 Scope

- `domain/evaluation_snapshot.go` — additive `Sparkline`, `ComputedAt` + camelCase JSON
- `domain/evaluation_refresh.go` — shared `EvaluationRefreshInterval` / `EvaluationStoreTTL`
- `application/ports/evaluation_store.go` — `EvaluationStore` port
- `application/market/` — `EnrichFromSparkline`, `SnapshotsFromRankings`
- `application/evaluation/` — `Refresher` (lock, backoff, stagger); thin convert re-export
- `infrastructure/evaluation/redis_evaluation_store.go` — Lua Put (temp→RENAME);
  store-local `redis.Nil` → miss; compare-and-del lock Release
- `infrastructure/symbol_universe/redis_client.go` — Eval, SetNX (Get/HGet still return
  `redis.Nil` for misses — unchanged shared contract)
- `cmd/api/main.go` — default-on `PC_EVAL_REFRESH` (disable with `0`); uncached
  rankings; Redis lock + store freshness

Out of scope: migrating any readers (PR-089b); HTTP API / COMMON.md changes.

1️⃣ Port

```go
type EvaluationStore interface {
    Put(ctx, tf string, evals []EvaluationSnapshot, computedAt time.Time) error
    Get(ctx, tf string) ([]EvaluationSnapshot, time.Time, error)
    GetSymbol(ctx, tf, symbol string) (EvaluationSnapshot, time.Time, error)
}
```

Miss (empty key / `redis.Nil`) → `ports.ErrEvaluationNotFound`. Redis transport /
AUTH errors are wrapped and returned as-is (fail closed for PR-089b).

2️⃣ Redis keys (tf validated via `domain.NewTimeframe`)

- `eval:{tf}` → JSON array (camelCase)
- `eval:{tf}:at` → unix seconds
- `eval:{tf}:sym` → hash field=symbol → JSON snapshot
- `eval:{tf}:sym:tmp` → staging hash during Put (orphans expire via TTL)

Put is a single Lua `EVAL`: build hash on `sym:tmp` → `RENAME` onto live `sym`
(or `DEL` live when empty) → `SET` array/at with `EX`. Live hash is never `DEL`ed
before the replacement is ready. TTL = `domain.EvaluationStoreTTL`
(`max(10m, 2 × refreshInterval)`).

Reads are generation-atomic: `Get` uses `MGET` (array+at); `GetSymbol` uses Lua
(`HGET` field + `GET` at) so the returned `time.Time` matches the snapshots.

Empty Put writes `[]` with a fresh `at` (valid empty snapshot, **not** a miss).

3️⃣ Refresher

- Default **on** (ROADMAP); `PC_EVAL_REFRESH=0|false|no|off` disables.
- Uses **uncached** `getRankingsUC` — intentional full score cost when due.
- Redis `SET NX` lock per `eval:refresh:{tf}`; **Release** is compare-and-del and
  always runs on an uncancellable context (`WithoutCancel` + 5s timeout) so
  shutdown cancel cannot leave a 30m lease stranded.
- After lock: read store `at`; if within `RefreshInterval`, skip Execute (shared
  freshness across replicas — avoids re-score after the winner releases).
- Empty rankings result → error + backoff; **does not** Put `[]` (preserves last good).
- Lock TTL = `DefaultLockTTL` = `max(30m, refreshInterval+30s)`.
- One timeframe per Tick (15s poll) — staggered warm-up.
- Failed Execute/Put → exponential backoff; `lastPut` stamped at Put **completion**.
- In-flight claim under mutex — concurrent Tick cannot double-run the same tf.
- Timeframes `15m`, `1h`, `4h`, `1d`. Interval `domain.EvaluationRefreshInterval`.

🚀 Result

By default a single leader per timeframe keeps `eval:{tf}` warm (disable with
`PC_EVAL_REFRESH=0`). Nothing user-facing changes yet — PR-089b switches readers
onto the store.

📝 Implementation notes

- Default on (ROADMAP); uncached `getRankingsUC`. Multi-replica: SET NX lock +
  compare-and-del Release + post-lock store freshness check (shared interval).
- Lock TTL floor **30m** (safety net); **Release on done** with
  `context.WithoutCancel` so restart after cancel is not blocked for 30m.
- `lastPut` stamped at Put **completion** wall time, not Tick start.
- Empty rankings → error/backoff, never Put `[]` (preserves last good hash).
- Put Lua: temp→RENAME then SET array/at. Abort after temp leaves live intact
  (tested); orphan `sym:tmp` expires via TTL. Mid-script abort after RENAME but
  before SET array remains a rare skew healed by the next Put.
- `redis.Nil` mapped to miss **inside** RedisEvaluationStore only.
- Conversion lives in `application/market.SnapshotsFromRankings`.
- Intentional empty Put (if ever needed) would write `[]` + fresh `at` (not a
  miss). PR-089b must treat empty vs missing explicitly.
