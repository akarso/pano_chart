## PR-098a: Sector composites (backend)

**Layer:** application + adapters + infrastructure. **Depends on:** PR-095.

### Scope

- Exclusive `sectors.yaml` membership; missing auto path → warn + skip route; explicit `SECTORS_CONFIG_PATH` / bad YAML → fatal
- One bar fan-out; market from same `paths`; RS on **clamped** timestamp intersection + `rsAvailable`
- `points` / `return` / `rs` share the clamped window; `points` rebased to 100 at first shared stamp
- `marketSymbolCount` on the response; Redis caches any non-empty payload (`min(3m, tf/2)`); empty not cached

### Out of scope

Frontend Market Pulse “Sector rotation” card (PR-098b).

### Tests

- Candle-skew clamp → clamped/rebased `points` match `return`/`rs` + cache hit
- Start-trim rebase → `points[0]=100`, return/rs unchanged
- Hand-computed VW RS; path policy; sort unavailable last
- Handler: `4H` normalize, limit clamp/`abc`, `marketSymbolCount`
- Missing `sectors.yaml` wraps `fs.ErrNotExist`
