## PR-106: Trend health v2 for participation fallback

**Layer:** application. **Depends on:** PR-088, PR-115 (tape path already on V2).

### Context

PR-115 moved `ComputeTrendHealthV2`, Wilder `TrueATR`, and the wider drawdown
curve onto the composite tape. Tape structure no longer passes through
`DampenTrendByHealth`. This PR finishes the ROADMAP slice for the **legacy
participation fallback** (no tape / empty composite).

### Scope

- Participation health uses `TrendHealthFromSnapshot` → `ComputeTrendHealthV2`
  (sparkline ≥ 15: close-only Wilder ATR14, window extremes, staleness, 8-bar
  adverse tail; otherwise enriched snapshot fields with `barsSinceExtreme = 0`).
- Tokens with `ATR == 0` are still scored when a long sparkline yields
  TrueATR > 0; flat long sparklines are skipped (no baseline).
- `EnrichFromSparkline`: ATR14 when `len ≥ 15`, else mean |Δclose|.
  **`RecentReturn` is always full-window / mean|Δclose|** (silent override +
  bias override keep their pre-PR-106 scale; Wilder is not the return
  denominator). The 8-bar crash tail is health-only on the sparkline path;
  short / field-only rows still feed full-window `RecentReturn` into the V2
  crash penalty (over-penalize risk for short fixtures only — production
  sparklines are ~110 bars).
- Participation captions use `BuildTapeLabel(state, …)` so State=trend cannot
  disagree with a prevalence-gated "Mixed conditions" label.
- `DampenTrendByHealth`: minimum damp factor **0.35** (was 0.1).

### Stacking note

V2 drawdown tolerance (2 ATR ≈ health 0.6, not a breakdown) plus the 0.35
dampen floor means a badly broken all-trend book redistributes to ~35% trend
weight rather than a ~10% stub. Captions then usually leave "Strong trend"
via prevalence drop / declassification, not only via the breaking-down branch.

### Out of scope

- Per-token setup health (`computeRegimeAndHealth` still V1 mean ATR).
- Tape scoring (unchanged since PR-115).
- Golden `messy_uptrend` dampening ratio (tape never dampened post-115).
- Filtering NaN sparkline points.

### Tests

- `TrendHealthFromSnapshot` long path: 2 ATR → ≈0.6 after light staleness;
  staleness ≈ 0.5; bogus Price/High/ATR ignored when sparkline is long.
- `TrendHealthFromSnapshot` short path: enriched fields with `barsSince=0`.
- `Calculate` with production-length sparklines; positive `BreakdownRate`
  under V2 (≥ 3.5 ATR); 2 ATR not a breakdown; ATR-unset sparkline scores;
  fully broken book hits damp floor and is not labelled Strong trend.
- `EnrichFromSparkline`: Wilder ATR14 diverges from mean|Δ| on unequal moves;
  RecentReturn uses mean|Δ| denominator.
- Flat long sparkline excluded from breakdown averaging; dampened trend
  State/label stay in agreement.
