## PR-115: fix(market): tape verdict must match the composite chart

🎯 Objective

A trending composite chart was labelled SIDEWAYS because health dampening
moved trend weight onto Sideways (which measured zero) and Trend
Predictability zeroed itself on normal pullbacks. After this PR the headline
and the chart agree: measured structure only, TapeTrend for the trend
component, TREND only when TapeTrend ≥ 0.5.

See ROADMAP Hotfixes — PR-115.

🧱 Scope

- `domain/scoring/stats.go` — `OLSSlopeR2`, `TrueATR` (Wilder), `clamp01`
- `domain/scoring/tape_trend.go` — `TapeTrend` (no shape / cluster gates)
- `application/market/health.go` — `ComputeTrendHealthV2`; label thresholds
  aligned with V2 (strong > 0.75, weakening > 0.4)
- `application/market/tape_regime.go` — exclusive TREND gate; OHLC extremes;
  crash penalty on an 8-bar tail; label from TapeTrend when state is trend
- `application/market/market_state_service.go` — `windowBars = series.Len()`,
  count-based `participation` from stored evals
- HTTP DTOs; `COMMON.md`; coherence + golden tests

Out of scope: PR-116 UI; changing rankings / AlgoVersion (tape-only change);
`DampenTrendByHealth` floor (participation fallback keeps V1 health).

1️⃣ Exclusive TREND gate

`State = trend` only when raw `TapeTrend ≥ 0.5`. Below that, state is chosen
among sideways / compression / expansion (never a normalised singleton trend
mix). When state is trend, `confidence = TapeTrend` (not mix share).

2️⃣ Label / health

`BuildTapeLabel` matches `state`: trend uses V2 health; compression /
expansion / sideways / indecisive / silent get their own captions (not a
shared `"No clear trend"`). Fallback uses V1 `BuildMarketLabel` only when
`state` is trend; otherwise the same state-matched captions. Silent clears
to `"No clear trend"`. Health / breakdownRate only at the TapeTrend gate.

3️⃣ Window extremes / crash

Window high/low and `barsSinceExtreme` use candle OHLC. Adverse-move
`recentReturn` is the last 8 bars / `atr14` (documented in COMMON.md).

4️⃣ Participation

Counts `|EvaluationSnapshot.TrendScore| ≥ 0.5` (Trend Predictability) with
sparkline Bias. Documented distinctly from response `trendScore` (TapeTrend).

✅ Definition of Done

- [x] TREND requires TapeTrend ≥ 0.5; weak mix cannot promote TREND or a trend caption
- [x] Coexistence: TapeTrend ≥ 0.5 with compression-heavy mix → TREND, confidence = raw score
- [x] 2 ATR pullback → health ≈ 0.6 and label "Trend weakening"
- [x] 8-bar adverse dump applies the crash penalty
- [x] `windowBars` = scored length; 0 on participation / unavailable
- [x] COMMON.md points at TapeTrend; fallback label thresholds unchanged

🚀 Result

Clean / pullback / noisy +12% composites read TREND with measured Sideways
near zero. A 2 ATR dip weakens the caption without flipping the state.
