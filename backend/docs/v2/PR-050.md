## PR-050: feat(behavior): add retail behavior engine
🧠 Concept

We translate raw signals into behavioral dimensions:

greed
fear
patience
panic

These are not predictions — they are interpretations of current positioning + flow.

1️⃣ Domain Model

domain/behavior/retail_behavior.go

package behavior

type RetailBehavior struct {
    Symbol    string
    Timeframe string

    Greed     float64
    Fear      float64
    Patience  float64
    Panic     float64

    Summary   string
}

3️⃣ Behavior Engine

application/behavior/engine.go

type Engine struct{}
Greed

Driven by:

high funding
long imbalance
oi expansion
func greed(ctx BehaviorContext) float64 {

    score :=
        ctx.FundingExtremeness * 0.4 +
        ctx.Imbalance * 0.4 +
        ctx.OIExpansion * 0.2

    return clamp(score)
}
Fear

Opposite of greed but not symmetrical.

Driven by:

fragility + volatility
func fear(ctx BehaviorContext) float64 {

    score :=
        ctx.FragilityScore * 0.6 +
        ctx.Volatility * 0.4

    return clamp(score)
}
Patience

Retail is patient when:

low volatility
compression regime
low volume spikes
func patience(ctx BehaviorContext) float64 {

    compressionBoost := 0.0
    if ctx.Regime == "compression" {
        compressionBoost = 0.3
    }

    score :=
        (1 - ctx.Volatility) * 0.5 +
        (1 - ctx.VolumeScore) * 0.2 +
        compressionBoost

    return clamp(score)
}
Panic

This is the most important one.

Driven by:

fragility
volatility spike
liquidation proximity (already inside fragility)
func panicScore(ctx BehaviorContext) float64 {

    score :=
        ctx.FragilityScore * 0.5 +
        ctx.Volatility * 0.5

    return clamp(score)
}
4️⃣ Engine Output
func (e *Engine) Evaluate(ctx BehaviorContext) behavior.RetailBehavior {

    g := greed(ctx)
    f := fear(ctx)
    p := patience(ctx)
    pa := panicScore(ctx)

    summary := summarize(g, f, p, pa)

    return behavior.RetailBehavior{
        Greed: g,
        Fear: f,
        Patience: p,
        Panic: pa,
        Summary: summary,
    }
}
5️⃣ Human-readable Summary (no LLM needed)

This is important for UX.

func summarize(g, f, p, pa float64) string {

    if pa > 0.7 {
        return "Panic rising"
    }

    if g > 0.7 {
        return "Greed dominant"
    }

    if p > 0.6 {
        return "Market waiting / coiling"
    }

    if f > 0.6 {
        return "Fear elevated"
    }

    return "Neutral sentiment"
}
6️⃣ Service Layer
type Service struct {
    engine *Engine
    dataProvider DataProvider
}

func (s *Service) Get(symbol, timeframe string) (behavior.RetailBehavior, error) {

    data := s.dataProvider.Get(symbol, timeframe)

    ctx := BehaviorContext{
        FragilityScore: data.FragilityScore,
        FundingExtremeness: data.FundingExtremeness,
        OIExpansion: data.OIExpansion,
        Imbalance: data.Imbalance,
        Regime: data.Regime,
        VolumeScore: data.VolumeScore,
        Volatility: data.Volatility,
    }

    return s.engine.Evaluate(ctx), nil
}

🔥 Very important (built-in improvement)

To avoid nonsense states like:

high greed + high fear simultaneously

We softly normalize:

total := g + f + p + pa

if total > 1.5 {
    scale := 1.5 / total
    g *= scale
    f *= scale
    p *= scale
    pa *= scale
}

This keeps behavior realistic.
