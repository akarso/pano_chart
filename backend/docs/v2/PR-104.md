## PR-104: Sideways variance-ratio mean-reversion component

**Layer:** domain (+ thin setup wiring). **Depends on:** PR-088.

### Product decision

`MeanReversionScore` / `VarianceRatio` measure **Lo–MacKinlay return
autocorrelation**, not channel / range quality. Smooth oscillating channels
(golden `tight_range`) typically have VR ≫ 1 and MRS ≈ 0. That is expected.

Consequences for PR-110: do **not** gate `RangeQuality` on this MRS while
treating `tight_range` as the golden range — either amend PR-110 to use a
channel-aligned quality signal, or accept that LM-MR ranges differ from
structural sideways. Production `mean_reversion_weight` stays **0.0**.

### Scope

- `VarianceRatio(closes, q)` in `domain/scoring/stats.go` — overlapping
  Lo–MacKinlay `VR(q) = Var(r_q) / (q × Var(r_1))` on log returns. Non-finite
  / non-positive closes → neutral `1`.
- `MeanReversionScore(closes)` — average of `clamp((1 − VR(q)) × 1.5, 0, 1)`
  for `q = 4` and `q = 8`.
- Sideways V5 gains `MeanReversionWeight` / YAML `mean_reversion_weight`
  (default **0.0** → no ranking behavior change, MRS work skipped). When > 0,
  MRS joins the weighted average; `"MRS"` appears in Components only then.
  Negative weights clamped to 0 at config load / detect.
- `SetupContext.MeanReversionScore` = MRS on the **same** trailing window as
  Sideways V5 (`CandleCount`, default 110). Go zero value is 0 (no MR —
  fail-closed for PR-110). No raw VR(4)-only field (callers would miss q=8).

### Out of scope

- Flipping `mean_reversion_weight` above zero in production.
- Range trade planner (PR-110) / amending ROADMAP RangeQuality.
- Treating `tight_range` as an MRS golden (it is not, under LM).

### Tests

- Seeded AR(1) φ = −0.5 → VR(4) < 0.8; MeanReversionScore ≥ 0.5.
- Seeded random walk → VR(4) ∈ [0.85, 1.15].
- Seeded momentum AR(1) φ = +0.5 → VR(4) > 1.2 (replaces ROADMAP
  “trend+noise”, which yields VR≈1 under this estimator).
- `tight_range` MRS ≈ 0 (channel ≠ LM mean reversion).
- NaN / Inf / non-positive / short / flat → neutral VR=1, MRS=0.
- Default weight 0: no `"MRS"` key; score equals four-term CCS/OQS/DCS/VOS×SRM.
- Weight > 0: five-term weighted average; dilution on `tight_range` (MRS≈0).
- Negative weight (config + detect) treated as 0 / four-term identity.
- `meanReversionFromSeries` matches `MeanReversionScore(last CandleCount)`.
- `NewSidewaysV5ConfigForTimeframe` default `MeanReversionWeight == 0`.
