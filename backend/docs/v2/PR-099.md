## PR-099: Multi-timeframe regime stack (backend)

**Layer:** application + adapters. **Depends on:** PR-089b.

### Scope

- `application/mtf.Service`: for each of `["15m","1h","4h","1d"]` (shared with
  `application/evaluation.DefaultTimeframes`), reads `EvaluationStore.GetSymbol`,
  builds the four-way structure via the now-exported `market.ScoreWeights`,
  and picks the dominant regime as the max weight
- `Alignment` = share of frames agreeing with the most common dominant
  regime (0–1); `AlignedState` = that regime when `Alignment ≥ 0.75`, else `indecisive`
- A frame is silently omitted (not an error) when its store entry is missing,
  stale (`domain.EvaluationStoreFresh`), or from a different `AlgoVersion`;
  `Alignment`/`AlignedState` are computed over whatever frames remain (`0`
  and `indecisive` when none do). Only a context cancellation/deadline from
  the store aborts the whole call
- `GET /api/symbol/{symbol}/regimes` — new `SymbolRouter` dispatches the
  `/regimes` suffix to a new `MTFHandler`; a bare `/api/symbol/{symbol}` still
  reaches `SymbolDetailHandler` exactly as before
- `GET /api/rankings?mtf=1` adds `alignment`/`alignedState` (omitempty) to
  each row via a best-effort overlay applied only to the returned page (not
  the full universe) — the overlay is a pure store read, no candle fetch or
  rescoring. Rows are looked up concurrently (bounded to 16 in flight) under
  one shared deadline (300ms) for the whole page, so a slow/hung store adds
  bounded latency regardless of page size instead of serializing up to
  `pageSize × 4` sequential Redis round-trips on the request goroutine. A
  calculator error, an unset param, or the shared deadline firing leaves a
  row's fields unset; a summary line (not one per row) is logged when any
  rows were skipped

### Out of scope

Frontend MTF strip / aligned badge (PR-100).

### Tests

- Four frames all trend → alignment 1.0, alignedState trend
- Two trend, two sideways → alignment 0.5, alignedState indecisive
- Missing / stale / algo-version-mismatched frame → skipped, alignment over
  remaining frames
- No frames available → alignment 0, alignedState indecisive
- Store transport error → frame skipped, not an error; context
  cancellation → propagated
- Handler: happy path, invalid path/symbol, method not allowed, calculator error
- `SymbolRouter`: `/regimes` suffix vs bare symbol dispatch
- Rankings `?mtf=1`: fields added only when requested; calculator error or
  unset param leaves the row unaffected; nil calculator does not panic
- Rankings `?mtf=1` at the `pageSize=200` cap: all rows correctly
  index-aligned under concurrency (`-race` clean); a permanently hung
  calculator still returns within the shared overlay deadline instead of
  stalling the response
