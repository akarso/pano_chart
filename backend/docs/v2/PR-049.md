Core idea

We measure position stress, not direction.

2️⃣ Funding Extremeness

We don’t care about raw funding — we care how extreme it is.

funding_model.go

func fundingExtremeness(funding float64) float64 {

    abs := funding
    if abs < 0 {
        abs = -abs
    }

    // normalize assuming ~0.01 is extreme
    score := abs / 0.01

    if score > 1 {
        score = 1
    }

    return score
}

Interpretation:

high funding → crowded side → fragile
3️⃣ Open Interest Expansion

We detect fast positioning build-up.

oi_model.go

func oiExpansion(oiSeries []float64) float64 {

    if len(oiSeries) < 10 {
        return 0
    }

    start := oiSeries[len(oiSeries)-10]
    end := oiSeries[len(oiSeries)-1]

    if start == 0 {
        return 0
    }

    growth := (end - start) / start

    if growth < 0 {
        return 0
    }

    if growth > 1 {
        return 1
    }

    return growth
}
4️⃣ Long/Short Imbalance

If market is heavily skewed → fragile.

imbalance_model.go

func imbalance(longRatio float64) float64 {

    // longRatio = 0.5 neutral

    diff := longRatio - 0.5
    if diff < 0 {
        diff = -diff
    }

    return diff * 2 // normalize to 0–1
}
5️⃣ Liquidation Proximity

You already have liquidity clusters — perfect input.

liquidation_model.go

func liquidationProximity(
    price float64,
    nearestCluster float64,
) float64 {

    if price == 0 {
        return 0
    }

    distance := nearestCluster - price
    if distance < 0 {
        distance = -distance
    }

    ratio := distance / price

    score := 1 - ratio*10

    if score < 0 {
        return 0
    }

    if score > 1 {
        return 1
    }

    return score
}

Closer clusters → higher fragility.

6️⃣ Fragility Engine

This is where we combine — carefully.

fragility_engine.go

type Engine struct{}

func (e *Engine) Calculate(
    funding float64,
    oiSeries []float64,
    longRatio float64,
    price float64,
    cluster float64,
) risk.FragilityComponents {

    return risk.FragilityComponents{
        FundingExtremeness: fundingExtremeness(funding),
        OIExpansion:        oiExpansion(oiSeries),
        LongShortImbalance: imbalance(longRatio),
        LiquidationProximity: liquidationProximity(price, cluster),
    }
}
7️⃣ Final Score (important part)

We do NOT blindly average.

We weight based on reliability:

funding → sentiment
oi → positioning
imbalance → skew
liquidation → trigger

Implementation:

func finalScore(c risk.FragilityComponents) float64 {

    score :=
        c.FundingExtremeness * 0.25 +
        c.OIExpansion * 0.30 +
        c.LongShortImbalance * 0.20 +
        c.LiquidationProximity * 0.25

    if score > 1 {
        score = 1
    }

    return score
}
8️⃣ Risk Level Mapping
func riskLevel(score float64) string {

    switch {
    case score > 0.7:
        return "high"
    case score > 0.4:
        return "medium"
    default:
        return "low"
    }
}
9️⃣ Service Layer

fragility_service.go

type Service struct {
    engine *Engine
    dataProvider DataProvider
}

func (s *Service) Get(symbol string, timeframe string) (risk.Fragility, error) {

    data := s.dataProvider.Get(symbol, timeframe)

    components := s.engine.Calculate(
        data.Funding,
        data.OISeries,
        data.LongRatio,
        data.Price,
        data.NearestCluster,
    )

    score := finalScore(components)

    return risk.Fragility{
        Symbol: symbol,
        Timeframe: timeframe,
        Score: score,
        RiskLevel: riskLevel(score),
        Components: components,
    }, nil
}
