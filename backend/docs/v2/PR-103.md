## PR-103: Trend Strength v2 (direction persistence)

**Layer:** domain + application + config. **Depends on:** PR-088, PR-094.

### Scope

- `TrendStrengthScoreCalculator` in `domain/scoring/trend_strength_score_calculator.go`.
  Calculator **weight key** stays `"Trend Predictability"` (same `Name()`) so rankings /
  scoreWeights need no key changes. Which engine ran is selected by
  `scoring.trend_algo` / `TREND_ALGO`, not by the JSON key.
- Config `scoring.trend_algo`: `predictability` (default) | `strength`, overridable
  via `TREND_ALGO` env. Invalid values warn at startup and fall back to predictability.
- `usecases.TrendCalcFor` + `main.go` wiring for rankings **and** setups
  (`SetupService.SetTrendDirectionCalc`) so overlay / `dominantRegime` use the same
  engine as WeightedSymbolScorer.
- Rankings Redis cache keys include `trend_algo` (alongside sideways algo +
  `AlgoVersion`) so toggling the flag cannot serve stale TotalScore.
- Evaluation snapshots stamp `TrendAlgo`; identity checks
  (`EvaluationIdentityOK(algo, got, want)`) reject mismatched rows. The eval
  store Redis keys and refresh locks are namespaced by trend algo so rolling
  deploys with mixed `TREND_ALGO` do not overwrite each other.

### Out of scope

- Flipping the default to `strength` (scorecard gate over ≥2 weeks).
- Tape / `ScoreMarketTape` switch (separate flag per ROADMAP).

### Tests

- Golden fixture thresholds: messy/clean uptrend, tight range, v-reversal,
  clean downtrend bias.
- Seeded random-walk average ≤ 0.25 over 100 seeds.
- `Score()` equals `ScoreWithDirection` magnitude; neutral bias on flat_dead.
- Documented side-by-side on `messy_uptrend`: logs companion predictability
  score; does not require strength > predictability (current golden already
  scores high under OLS R²).
- `ParseTrendAlgo` table; cache keys differ for predictability vs strength.
- Setup cold-path Evaluate with strength on scorer + `SetTrendDirectionCalc`
  does not `scoresAgree`-fail into sideways.
- Single price-level jump (flat→flat) scores low — path concentration kills ER.
- Eval refresher does not treat a fresh store from another trend algo as fresh.
