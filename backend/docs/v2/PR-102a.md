## PR-102a: Contextual alert payloads (backend)

**Layer:** application + domain. **Depends on:** PR-101a.

### Scope

- Pure `DownsampleSparkline(closes, target)` — for a 110-bar snapshot and
  target 30, indices `i*(n-1)/(target-1)` so first and last closes are
  kept and the result length is exactly 30. Empty or already-short series
  return a copy.
- `AlertContext` JSON blob attached as `Data["context"]` on every
  market / setup / watchlist push (FCM data is `map[string]string` only).
  Shape:

  ```json
  {
    "tapeRegime": "trend",
    "tapeBias": "up",
    "tapeConfidence": 0.62,
    "symbolScore": 0.81,
    "rs": 0.032,
    "alignment": 0.75,
    "sparkline": [/* 30 closes */]
  }
  ```

  Market broadcasts (no symbol) carry tape fields only. Symbol fields and
  sparkline are omitted when unavailable. Store miss never blocks the push.
- `EvaluationSnapshot` gains `TotalScore` (`*float64`) and
  `RelativeStrength`, filled by `SnapshotsFromRankings` from the ranked
  row so the scheduler can read score/RS from `EvaluationStore.GetSymbol`
  without a rankings scan. Absent `totalScore` in store JSON stays nil
  (no false `symbolScore: 0` for pre-deploy rows).
- Scheduler injects `ports.EvaluationStore`. Setup and watchlist builds
  also pull tape via `MarketProvider` and alignment via
  `RegimeStackProvider` when set. Symbol fields require current
  `AlgoVersion` + `EvaluationStoreFresh`; otherwise they are omitted
  (true fail-open). Context is cached per `(timeframe, symbol)` within
  each scheduler tick so cost scales with distinct keys, not subscribers.
  Empty context blobs are not attached.

### Out of scope

Frontend big-picture rendering (PR-102b). Composite-index sparkline on
market-only alerts. Changing the FCM HTTP envelope. Background / killed
rich notifications (documented in COMMON.md — foreground Android only).

### Tests

- `DownsampleSparkline`: 110→30 keeps first/last and length 30; empty and
  short inputs; target ≤ 1; non-finite drops
- `AttachContext`: JSON shape; tape-only; empty omits key; zero score /
  alignment present; non-finite sparkline keeps tape
- Snapshot conversion copies `TotalScore` / `RelativeStrength`
- Setup and watchlist sends include `context` with sparkline length 30 when
  a fresh matching snapshot is present; market includes tape keys without
  sparkline; missing / stale / wrong-algo snapshot still sends without
  sparkline/score; setup caches GetSymbol across subscribers
