## PR-096: feat(market): relative strength per symbol (backend)

🎯 Objective

Rankings show how each symbol moved versus the composite tape over the **same
calendar window** (timestamp overlap): log excess return (`rs`), OLS beta on those
pairs, and universe percentile (`rsRank`), plus sort modes `leaders` / `laggards`.

See ROADMAP Track C — PR-096. Depends on PR-095.

🧱 Scope

- `application/usecases/get_rankings.go` — `RankingsResult`, tape provider, RS filter,
  leaders/laggards fallback, `requestedSort`
- `application/usecases/relative_strength.go` — overlap, min overlap floor, OLS, RSRank
- `adapters/http/dto.go` + handler — `rsAvailable`, `requestedSort`, omitempty RS
- `infrastructure/rankings/redis_cached_rankings.go` — `rankings_v2`; skip SET on
  transient tape fail and leaders/laggards fallback; cache stable unscored non-RS
- `cmd/api/main.go` — cached composite + exclude filter; tape window 110
- `COMMON.md` / ROADMAP PR-097 chip: `rsAvailable && rs != null`

Out of scope: frontend UI (PR-097); building a second composite when sparkline
precision ≠ `CompositeTapeWindow` (RS always requests that shared window).

1️⃣ Same window

Spark timestamps ∩ tape preferred series. Score only when
`len(overlap) ≥ max(2, min(20, ceil(len(tape)/2)))`. Excluded stables stay unset.
Tape fetch uses `metrics.CompositeTapeWindow` (same const as Market Pulse).

2️⃣ Availability

`rsAvailable=true` only when a usable tape scored ≥1 row. Else log (except nil
provider), fall back leaders/laggards → `total`, expose `requestedSort`.

3️⃣ Cache

Skip Redis `SET` when `RSTransientFail` (tape fetch/short, incomplete candle
coverage, or capable-but-unaligned zero-scored) for any sort, and when
leaders/laggards fall back or return empty (`!RSAvailable`). Still cache non-RS
sorts when RS is stably unscored (precision below floor / all excluded / all
short history) or `RSDisabled`. Prefix `rankings_v2`.

✅ Definition of Done

- [x] Overlap + min floor; 2-stamp rocket does not outrank full-window name
- [x] Zero scored rows → `rsAvailable=false`, sort fallback
- [x] Transient tape miss does not poison Redis (any sort); empty leaders not cached
- [x] Stable unscored non-RS sorts still cache
- [x] `CalculateTape(..., CompositeTapeWindow)`; chip contract documented for PR-097
- [x] Gapped-overlap beta pinned to closed-form OLS
- [x] gofmt / go vet / tests clean

🚀 Result

Leaders/laggards sort on shared-window excess return without fake A–Z lists or
poisoned fallback caches. PR-097 must show the chip iff `rsAvailable && rs != null`.
