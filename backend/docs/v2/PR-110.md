## PR-110: Range trade planner (backend)

**Layer:** application + adapters. **Depends on:** PR-104, setups service.

### Scope

- `application/plan`: `BuildRangePlan` / `BuildRangePlanFromBounds`, pure
  `Size(accountRisk, entry, stop)`, and `Service.Evaluate` over
  `CandleRepositoryPort` (last 110 bars).
- Channel = confirmed swing highs/lows via shared `scoring.IsPivotHigh` /
  `IsPivotLow` (3-bar pivot). Edge bars cannot confirm (last-bar wick ignored);
  interior confirmed pivots — including wick spikes — do move High/Low.
- ATR = Wilder TrueATR(14) on the same window as the channel.
- Long: entry `Low+0.25×ATR`, stop `Low−1×ATR`, conservative target Mid,
  full target `High−0.25×ATR` (and short mirror). `LongStop ≤ 0` →
  `non-positive stop`.
- `RangeQuality` = Sideways V5 score (channel-aligned). **Not** Lo–MacKinlay
  MRS (PR-104 caveat: `tight_range` MRS≈0).
- `Valid` when quality ≥ 0.5 and `(High−Low)/ATR ≥ 3.5`. Width 3.5 encodes
  Mid-target RR≥1.2 (`RR = widthATR/2.5 − 0.2`); there is no separate public
  `"risk reward"` reason. When `!Valid`, entry/stop/target are zeroed;
  `riskReward` / `position` / channel fields stay for diagnostics.
- `GET /api/symbol/{symbol}/plan?timeframe=&risk=` via `PlanHandler` on
  `SymbolRouter` (`/plan` action). Candle miss → 422 `DATA_UNAVAILABLE`;
  cancel → 499; deadline → 504; unset/nil plan handler → 503.
- `COMMON.md` contract for the JSON DTO.

### Out of scope

- Frontend Plan tab (PR-111).
- Enabling production `mean_reversion_weight`.

### Tests

- Hand-built 100–110 ATR 1 → LongEntry 100.25, stop 99, Mid target, RR 3.8, Valid.
- `widthATR=3.2` → `channel width` (RR still reported); `widthATR=3.5` Valid with RR=1.2.
- Low quality / ATR 0 / degenerate / non-positive stop / insufficient bars;
  levels cleared, RR/position kept where computed.
- Ranging triangle series → `BuildRangePlan` Valid with real ATR + Sideways V5.
- Edge wick spike ignored by swing channel.
- `Service.Evaluate` sizes only when valid; data-unavailable vs context cancel.
- Handler happy path, nil evaluator 503, invalid zeros levels, risk/method/422/499;
  router `/plan` dispatch and 503 when unset.
