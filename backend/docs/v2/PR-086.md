## PR-086: perf(market): cache the composite tape per timeframe

🎯 Objective

`MarketStateService.Calculate` (PR-084) rebuilds the composite tape on every call by
constructing a `CompositeIndexService` inline and fanning out ~150 candle fetches.
The notification scheduler and setup scanner call `Calculate` frequently. Cache the
tape so warm calls are O(1) Redis reads.

See ROADMAP Track A — PR-086.

🧱 Scope

- `application/market` — `TapeProvider` + `SetTapeProvider`; `scoreCompositeTape` prefers it
- `infrastructure/market/redis_cached_composite.go` — `CalculateTape` + flat DTO + TF-aware TTL
- `cmd/api/main.go` — `marketService.SetTapeProvider(compositeUC)`

Out of scope: changing readers beyond MarketState (PR-089), composite math (PR-095),
frontend.

1️⃣ TapeProvider

```go
type TapeProvider interface {
    CalculateTape(ctx context.Context, timeframe string, limit int) (metrics.CompositeTape, error)
}
```

`scoreCompositeTape` uses `s.tape` when non-nil; falls back to inline
`NewCompositeIndexService(s.candles, …)` only when `s.tape == nil && s.candles != nil`.

2️⃣ Redis CalculateTape

- Key: `{prefix}:tape:{timeframe}:{limit}`
- Serialize flat DTO (`[]{T,O,H,L,C,V}` per series + PreferredSource + Index); rebuild with
  `NewCandleUnsafe` + `NewCandleSeries`
- TTL: `min(baseTTL, tf/2)` so 1m tapes expire in 30s, not 3 minutes

3️⃣ Wiring

`main.go`: after `SetCandleProvider`, `marketService.SetTapeProvider(compositeUC)`.

✅ Definition of Done

- [x] `RedisCachedComposite.CalculateTape` round-trips PreferredSeries Len + first/last close
- [x] Second `CalculateTape` within TTL performs zero candle fetches (spy provider)
- [x] `MarketStateService` with fake `TapeProvider` never calls `CandleProvider.Symbols`
- [x] 1m TTL = 30s; 1h TTL stays 3m
- [x] gofmt / go vet / go test clean for touched packages
- [x] No JSON API field changes (COMMON.md untouched)

🚀 Result

Market Pulse / notifications reuse the cached tape within TTL; candle fan-out happens
at most once per `(timeframe, limit)` window.

📝 Implementation notes

- `Calculate` (index-only path for the HTTP composite chart) keeps the fixed base TTL;
  only `CalculateTape` is timeframe-aware — that is what MarketState / future readers use.
- Empty series from DTO rebuild returns a zero `CandleSeries` (no error) so a cached empty
  universe stays empty after round-trip.
- When `TapeProvider` is set but returns an error / short series, Calculate falls back to
  participation headline — it does **not** silently re-fan-out via candles (avoids double
  work and keeps the “tape owns the path” contract testable).
