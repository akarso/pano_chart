## PR-095: fix(market): composite math v2 — align, log-return, exclude

🎯 Objective

`CompositeIndexService.CalculateTape` aligned symbols by array index, used
arithmetic price rebase, and included stables/wrappers in the universe. That
skewed the tape on missing bars and on round-trip moves. Rebuild the composite
with timestamp alignment, log-return aggregation, and configurable exclusions.

See ROADMAP Track C — PR-095. Depends on PR-086 (cached tape API unchanged;
cache key prefix bumped to `v3`).

🧱 Scope

- `application/market/metrics/composite_index_service.go` — timeline + log math
- `application/market/metrics/symbol_filter.go` — exclude list + regex
- `domain/scoring/config.go` + `config.yaml` — `composite.exclude`
- `cmd/api/main.go` — wire filter from loaded config via `EffectiveComposite`
- Tests in `tests/application/market/` + `symbol_filter_test.go`

Out of scope: rankings RS (PR-096), frontend, JSON field renames.

1️⃣ Timestamp alignment

Active symbols = names that print on the latest contiguous **run** of dense
tips (last-quarter floor: `need` when any tip clears 50%, else densest recent).
Far-ahead islands: every trailing island is keep or strip (no short-prefix
span-ratio leave-behind). Same-cohort tip-miss (`islandMax ≥ need` and every
island printer tip-continues) leaves the island for the tip-run. Otherwise
`keepContinuingIsland` requires `islandMax ≥ n/3` and either every printer
tip-continues, or `|island| ≥ 100` with **no** tip-window hits (pure resume —
half-new length islands strip), or a **tiny-stub** equal-density keep
(`|prefix| < 8`, `islandMax ≤ 3`, and `islandMax ≥ prefixMax`, LatestTip /
clean 3-vs-3 — not stub 5-vs-5 or a 19-bar staggered last-N). A kept minority
island moves the recent cutoff to its start. Trailing islands are detected at
`gap > robustStep`. Tip-run holes allow five missing bars (`runHoleBars = 6`);
six or more drop the prior side. `SymbolCount = len(active)`. Reference
timeline = timestamps with ≥50% print coverage among active; after the anchor,
only timestamps with ≥50% **return-pair** coverage consume a `limit` slot.
Then trim to the last `limit` bars. Never align by index `i`.

2️⃣ Log-return aggregation

Per symbol `r = ln(price_t / lastPositiveCloseBefore(t))` for O/H/L/C.
Aggregate median (equal-weight) or volume-weighted mean of returns.
`V_0 = 100`, `V_t = V_{t−1} × exp(agg_r)`. Synthetic OHLC uses the same rule
relative to the previous synthetic close; high/low clamped around open/close.

3️⃣ Exclusions

`config.yaml`:

```yaml
composite:
  exclude: [USDCUSDT, FDUSDUSDT, …]
  exclude_pattern: "^(USD|EUR)"
  # disable_exclusions: true   # explicit empty filter; bare `{}` still means defaults
```

Skipped before fetch. A missing or empty `composite:` block is filled from
`DefaultAppConfig()` via `EffectiveComposite` so exclusions cannot silently
disable. Set `disable_exclusions: true` to exclude nothing. Empty list + empty
pattern in `SymbolFilterFromConfig` still means “exclude nothing” for
intentional overrides after EffectiveComposite.

🚀 Result

The tape is a coverage-aligned, multiplicative index that ignores stables;
`market_composite_v3` avoids serving pre-PR-095 arithmetic tapes from Redis.

📝 Implementation notes

- ROADMAP regex `^(USD|EUR|.*USD)` would match every `*USDT` pair; config uses
  `^(USD|EUR)` plus an explicit exclude list (single source: `DefaultAppConfig`
  / `config.yaml` via `EffectiveComposite`).
- Previous close is the symbol's last positive print strictly before `ts`.
- Zero/non-positive OHLC prints are dropped before log.
- Volume weight = `Σ volume×close` over the fetched window (all positive bars).
- `DefaultSymbolFilter` never reads `GetConfig()` (order-independent).
- `closeBefore` uses a lazy sorted predecessor index (O(log n) after one build).
- `CalculateTape` splits fetch → assemble → aggregateAlongTimeline.
