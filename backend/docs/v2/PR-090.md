## PR-090: feat(signal): signal log (domain + storage + writers)

🎯 Objective

Record every user-facing call (badges, high-confidence setups, regime
changes, strong transition probs) so Track B can grade them later. API
unchanged; writers are best-effort and nil-safe.

See ROADMAP Track B — PR-090. Labels / Context align with PR-091 rules
before any production write.

🧱 Scope

- `domain/signal/` — `Signal`, `Outcome` stub, `Filter`, `SignalWithOutcome`
- `application/ports/signal_repository.go`, `signal_emitter.go`
- `application/signal/emitter.go` — Append + candle-boundary dedupe
  (provisional in-flight claim under lock; Append unlocked; last only after
  success; detached timeout ctx)
- `application/signal/labels.go` — PR-091 vocabulary mapping
- `application/signal/regime_writer.go` — `RegimeObserver` + Seed + bias;
  history lookup outside the change-detection mutex
- `infrastructure/signal/sqlite_repository.go` — `signals` + `outcomes`;
  `SetMaxOpenConns(1)`, `PRAGMA foreign_keys=ON`; env `PC_SIGNAL_DB`
- Writers: rankings badges, setups `Confidence ≥ 0.5`, regime composite
  observer, transition targets ≥ 0.5
- `application/market/compose_observers.go` — fan-out for Tracker + RegimeWriter
- `cmd/api/main.go` — soft-fail leaves emitters nil (`NewRegimeWriter(nil)`
  path); seed RegimeWriter from history when enabled

Out of scope: outcome rules / evaluator job (PR-091); scorecard API (PR-092);
async Append worker (optional further p99 relief — provisional claim already
avoids holding the global mutex through SQLite I/O).

1️⃣ Dedup

Key `(kind, symbol, timeframe, label)`; suppress repeats within the same
candle open (`Truncate(tf.Duration())`). Failures do not poison the map.
Unknown TFs truncate to the second (no silent 1h window). Map capped /
TTL-swept.

2️⃣ Writers / labels

| Kind | Gate | Label / Context |
|------|------|-----------------|
| badge | `BadgeComponent != ""` | `trend_up`/`trend_down`/`sideways`/`gain`; sideways stores `range_low`/`range_high` |
| setup | `Confidence ≥ 0.5` | `compression` / `range` / `breakout_up` / `breakout_down` / `trend_*`; range+compression store extremes |
| regime | regime ≠ previous for TF (Seed on boot) | `regime:{state}` + `Context["bias"]` ∈ {-1,0,1} |
| transition | any target prob ≥ 0.5 | `transition:{target}` |

Symbol-scoped emits skip when `price ≤ 0` or `atr ≤ 0`.
