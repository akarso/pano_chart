PR-032.md
Range Breakout Detector (Directional, Structure-Based)
1. Objective

Introduce a structural breakout detector that identifies:

Breakout Up

Breakout Down

From:

Established sideways range

With directional expansion

With confirmation characteristics

Without noise spikes

This feature integrates with sorting system as:

breakout_up

breakout_down

2. Conceptual Definition

A valid breakout requires:

Prior structural containment (range context)

Boundary breach

Directional follow-through

Volatility expansion

Structural progression confirmation

Breakout is not:

One-candle wick

Random volatility event

Continuation inside already trending move

3. Required Inputs

From existing pipeline:

30 candles

Swing detection (from sideways v4)

totalRange

meanPrice

Net Displacement Ratio

Range Stability Score

4. Detection Flow

Breakout detection has two phases:

Phase A — Range Context Validation

We first ensure breakout originates from real range.

Use simplified sideways pre-check:

rangeContextScore =
    (1 - NDR)
    * ODS
    * BoundaryClarity


If:

rangeContextScore < 0.4 → abort breakout detection


No range → no breakout.

Phase B — Breakout Qualification
4.1 Boundary Breach

Let:

upperBoundary = max(swingHighs)
lowerBoundary = min(swingLows)


Define breakout if last close:

close > upperBoundary + epsilon
OR
close < lowerBoundary - epsilon


Where:

epsilon = totalRange * 0.03


Prevents micro fake breaks.

4.2 Follow-Through Strength

Breakout candle must not be isolated.

Measure:

postBreakMovement =
    abs(close - boundary) / totalRange


Scoring:

≥ 0.15 → strong

0.08–0.15 → moderate

< 0.08 → weak (penalize)

4.3 Volatility Expansion

Compression before breakout is ideal.

Compute:

recentRange = range(last 5 candles)
priorRange  = range(previous 10 candles)
volExpansion = recentRange / priorRange


Scoring:

≥ 1.3 → strong expansion

1.1–1.3 → mild

< 1.1 → weak

This avoids slow drift beyond boundary.

4.4 Structural Confirmation

Check swing progression after breach.

For breakout up:

New swing high > previous swing high

No immediate lower low

For breakout down:

New swing low < previous swing low

No immediate higher high

Count structural confirmations in last 5 candles.

5. Scoring

Directional score computed separately.

5.1 Breakout Up
scoreUp =
    rangeContextScore
    * boundaryBreachScore
    * followThroughScore
    * volExpansionScore
    * structureConfirmationScore


Clamp to [0,1].

5.2 Breakout Down

Same logic mirrored.

6. Directional Output

Each symbol receives:

BreakoutUpScore   float64
BreakoutDownScore float64


Sorting options:

breakout_up

breakout_down

No combined breakout score.

User chooses direction.

7. Filtering Behavior

Optional threshold for badge:

Only show breakout badge if:

score >= 0.65


Prevents false positives flooding list.

8. Avoiding False Positives

Algorithm explicitly rejects:

Pure trend continuation (fails rangeContextScore)

Single wick spikes (fails followThroughScore)

Wide volatility chaos (fails boundary clarity)

Slow grind above boundary (fails volExpansion)

9. Performance Impact

All operations:

O(n)

Reuse swing structure

No regression

No heavy math

Negligible impact.
