# PR-068 — Shape Validation, Silent Regime & Indecisive State

## Goal

Improve regime detection accuracy with three additions:

1. **Trend shape penalty** — penalize trend scores when the chart shape contradicts the declared direction (e.g., tail collapse in an uptrend)
2. **Silent regime** — detect flat, low-volume markets that are not sideways-ranging but genuinely quiet
3. **Indecisive state** — surface ambiguous regime classifications when no single regime clearly dominates

Also syncs frontend display and push notifications with the two new states.

---

## Changes

### 1. Trend Shape Penalty

**File:** `domain/scoring/trend_predictability_score_calculator.go`

Added `trendShapePenalty()` — operates in normalized [0,1] price space:

- Normalizes closes via min-max scaling
- Inspects last 15% (tail) and first 15% (head) of the series
- **Uptrend:** tail must stay near the top (≥ 0.80 normalized); head near the top is mildly penalized
- **Downtrend:** mirror logic — tail near bottom, head near bottom mildly penalized
- 50% normalized drop in the tail → penalty approaches zero (0.02 floor)
- Head penalties are lenient (0.30 floor)
- Applied as multiplicative factor on the raw normalized score
- Series < 10 candles → no penalty (not enough data)
- Wiggle tolerance: 20% in normalized space to avoid penalizing linear trends

### 2. Silent Regime

**Files:** `domain/market/market_state.go`, `application/market/market_state_service.go`, `infrastructure/market/rankings_evaluation_provider.go`

New `StateSilent` state for markets with:

- Dominant state is sideways or indecisive
- Average absolute return < 0.5× ATR (flat price action)
- Volume data available (median volume > 0)
- Average volume ≤ 1.5× median volume (no unusual spikes)

Helper `aggregateActivityMetrics()` computes avgAbsReturn, avgVolume, medianVolume.

Volume field added to `EvaluationSnapshot` construction in rankings provider.

### 3. Indecisive State

**Files:** `domain/market/market_state.go`, `application/market/market_state_service.go`

New `StateIndecisive` state fires when:

- Max breadth across all regimes < 0.50, OR
- Gap between first and second highest breadth < 0.30

Helper `topTwo()` extracts the two highest breadth values.

### 4. Frontend Display

**File:** `frontend/lib/features/market_state/market_pulse_screen.dart`

- Silent → `Colors.white` + `Icons.horizontal_rule`
- Indecisive → `Color(0xFFB0C4DE)` (grayish light blue) + `Icons.help_outline`

### 5. Push Notifications

**File:** `application/notifications/scheduler.go`

- **Indecisive:** suppressed — no push notification sent
- **Silent:** legacy broadcast → "Market is quiet — low activity"
- User-specific path: `StateIndecisive` guard prevents regime candidate pushes for indecisive timeframes; silent maps to "Silent" label under sideways candidate
