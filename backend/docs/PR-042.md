# PR-042: Google Play Billing Integration

## Objective

Integrate Android in-app subscription purchases using Google Play Billing.

This enables users to subscribe to the Pro plan directly inside the Android application.

---

# 1. Dependencies

Add the Google Play Billing library.

Android Gradle dependency:

```
com.android.billingclient:billing:6.0.1
```

---

# 2. Product Configuration

Define subscription product in Google Play Console.

Example:

```
product_id: pano_pro_monthly
type: subscription
price: EUR4.99/month
```

---

# 3. Billing Client Initialization

Create a billing manager responsible for handling purchases.

Responsibilities:

* connect to Google Play billing service
* query product details
* launch purchase flow
* receive purchase result

---

# 4. Purchase Flow

```
User taps Upgrade
↓
Launch Google purchase dialog
↓
Google processes payment
↓
App receives purchase token
↓
Send purchase token to backend
↓
Backend verifies purchase
↓
Subscription activated
```

---

# 5. Purchase Verification

Backend verifies purchase using Google Play Developer API.

Endpoint:

```
GET
/androidpublisher/v3/applications/{packageName}/purchases/subscriptions/{subscriptionId}/tokens/{token}
```

Verification confirms:

* purchase state
* expiration time
* renewal status

---

# 6. PaymentProvider Implementation

Implement provider adapter.

```
GooglePlayProvider implements PaymentProvider
```

Responsibilities:

* verify purchase token
* map Google response to PaymentVerificationResult

---

# 7. Handling Subscription Renewals

Google automatically renews subscriptions.

Backend must update expiration when:

* new purchase token appears
* renewal webhook arrives

---

# 8. Restore Purchases

Users must be able to restore subscriptions.

Flow:

```
App queries existing purchases
↓
Send purchase tokens to backend
↓
Backend verifies
↓
Subscription restored
```

---

# 9. Security Requirements

* never unlock premium from client
* always verify purchase token server-side
* store transaction ID to prevent replay

---

# 10. UI Changes

Add upgrade screen:

```
Upgrade to Pro
EUR4.99 / month

[ Subscribe ]
```

If user already subscribed:

```
Manage subscription
```

This opens Google Play subscription management.

---

# 11. Acceptance Criteria

* Billing client connects successfully
* Product details retrieved
* Purchase flow launches
* Purchase token sent to backend
* Backend verifies purchase
* Subscription activated
* Restore purchases works
