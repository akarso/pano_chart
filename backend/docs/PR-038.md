PR-038: Structural Breakout Detector (Directional Release Engine)
Overview

Introduce a Breakout Detection Engine that identifies structural range releases.

Breakout is defined as:

A decisive boundary violation with volatility expansion and directional conviction.

This engine is:

Independent from Sideways

Aligned with Compression (optional boost)

Directional (Up / Down)

Volume-aware (conviction confirmation)

Designed to avoid late-momentum chasing

Goals

Detect boundary break above resistance or below support.

Confirm volatility expansion.

Confirm directional body conviction.

Optionally confirm volume expansion.

Penalize “fake” low-energy breakouts.

Produce:

BreakoutUpScore

BreakoutDownScore

Subscores for analysis

Non-Goals

No pattern classification (flags, wedges, etc).

No statistical expectancy modeling.

No trade management logic.

No entry timing system.

Structural Model

Breakout requires five components:

Boundary Violation

Close Conviction

Volatility Expansion

Volume Confirmation (optional weight)

Pre-Break Compression Boost (optional)

1️⃣ Boundary Definition

We reuse channel boundaries from:

Sideways engine (if active)
OR

Compression engine (preferred)
OR

Rolling percentile band fallback

upper := channel.Upper(currentIndex)
lower := channel.Lower(currentIndex)
2️⃣ Boundary Violation Score (BVS)

Compute penetration depth:

penetrationUp   := (close - upper) / ATR
penetrationDown := (lower - close) / ATR

Score:

BVS_up   = clamp(penetrationUp / penetrationNorm, 0, 1)
BVS_down = clamp(penetrationDown / penetrationNorm, 0, 1)

If no boundary violation → score = 0.

This avoids binary detection.

3️⃣ Close Conviction Score (CCS)

We want candle bodies, not wicks.

bodySize := abs(close - open)
candleRange := high - low
bodyRatio := bodySize / candleRange

Directional:

if close > upper && close > open:
    CCS_up = bodyRatio
if close < lower && close < open:
    CCS_down = bodyRatio

Penalize wick breakouts.

4️⃣ Volatility Expansion Score (VES)

We want ATR increasing.

atrSlope := slope(recentATR)

Score:

if atrSlope > 0:
    VES = clamp(atrSlope / atrNorm, 0, 1)
else:
    VES = 0

This avoids late breakout during volatility contraction.

5️⃣ Volume Expansion Score (VLS)

Optional but recommended.

volumeZ := (currentVolume - meanVolume) / stdVolume

Score:

if volumeZ > 0:
    VLS = clamp(volumeZ / volumeNorm, 0, 1)
else:
    VLS = 0

Volume growing = higher conviction.

6️⃣ Pre-Break Compression Boost

If CompressionScore > threshold:

CompressionBoost = 0.5 + 0.5 * CompressionScore

Else:

CompressionBoost = 1.0

This aligns regimes:

Compression → Release

No compression → lower confidence breakout

Final Breakout Score Composition

Multiplicative core:

core_up =
    pow(BVS_up, w1) *
    pow(CCS_up, w2) *
    pow(VES, w3)

Add volume influence:

core_up *= (0.5 + 0.5 * VLS)

Apply compression boost:

BreakoutUpScore = core_up * CompressionBoost

Same mirrored logic for Down.

False Breakout Mitigation

To avoid “three candles sticking out”:

Add re-entry penalty:

If:

Price closes back inside boundary within N candles

Then:

BreakoutScore *= failurePenalty

Optional but powerful for reducing noise.

Alignment with Sideways

Breakout should suppress Sideways dominance.

Rule:

If:

BreakoutUpScore > breakoutDominanceThreshold

Then:

SidewaysScore *= sidewaysSuppressionFactor

This prevents:

“High sideways ranking with breakout happening.”

Mutual exclusivity emerges naturally.

Output Structure
type BreakoutResult struct {
    UpScore   float64
    DownScore float64

    BoundaryViolationScore float64
    CloseConvictionScore   float64
    VolatilityExpansionScore float64
    VolumeScore            float64

    CompressionBoost       float64
}
Configurable Parameters
type BreakoutConfig struct {
    ATRPeriod int
    VolumeLookback int

    PenetrationNorm float64
    ATRNorm float64
    VolumeNorm float64

    ReentryLookback int
    FailurePenalty float64

    CompressionThreshold float64
}

All tunable via MetaScore.

Behavior Across Regimes
Regime	Breakout Score
Clean compression	High potential
Sideways	Medium
Strong trend continuation	Moderate
Low volatility drift	Low
Wick fakeout	Low
Acceptance Criteria

Up and Down scores normalized [0,1]

Volume optional but supported

Compression boost integrated cleanly

Sideways suppression functional

No significant performance degradation

Strategic Impact

This engine enables:

Early directional sorting

Compression → Release pipeline

Pre-break positioning (if tuned correctly)

Mutual exclusivity across regimes

This is not a momentum scanner.

It is a structural release detector.
