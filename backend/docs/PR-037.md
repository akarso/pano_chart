PR-037: Compression Detector (Geometry-Agnostic Structural Tension Engine)
Overview

Introduce a Compression Score Engine that detects structural market tightening prior to potential expansion.

Compression is defined as:

Decreasing channel width + decreasing volatility + structural convergence + directional boundary pressure.

This detector is:

Independent from Sideways engine

Independent from Breakout engine

Purely structural (no TA folklore pattern labels)

Fully composable into MetaScore

Goals

Detect volatility contraction.

Detect channel width contraction.

Detect boundary convergence.

Detect directional pressure bias.

Produce:

CompressionScore

CompressionBias

Subscores for MetaScore composition.

Non-Goals

No breakout confirmation.

No wedge/triangle classification.

No probabilistic modeling.

No dependency on sideways score.

Structural Model

Compression requires four independent structural components:

Width Contraction

Volatility Contraction

Boundary Convergence

Directional Pressure

All must be measurable and normalized.

1️⃣ Channel Construction

Using existing swing detection (local extrema via N lookback):

type SwingPoint struct {
    Index int
    Price float64
    Type  string // "high" | "low"
}

We compute:

Upper regression line through highs

Lower regression line through lows

type Channel struct {
    UpperSlope float64
    LowerSlope float64
    UpperIntercept float64
    LowerIntercept float64
}

Channel width at index i:

width[i] = upper(i) - lower(i)
2️⃣ Width Contraction Score (WCS)

We compute linear regression on width series:

widthSlope = slope(widthSeries)

Scoring:

If widthSlope >= 0 → score = 0

If widthSlope < 0 → normalize magnitude

WCS = clamp(-widthSlope / maxExpectedSlope, 0, 1)

Optional weighting by duration.

3️⃣ Volatility Contraction Score (VCS)

Using ATR:

atrSlope = slope(ATR_series)

Scoring:

atrSlope >= 0 → score = 0

atrSlope < 0 → normalize

VCS = clamp(-atrSlope / maxExpectedATRDrop, 0, 1)

This ensures low volatility = compression candidate.

4️⃣ Boundary Convergence Score (BCS)

Measure slope relationship:

True convergence requires:

UpperSlope < 0

LowerSlope > 0
OR

Absolute difference between slopes decreasing

Compute:

slopeDelta = UpperSlope - LowerSlope

We want slopeDelta shrinking over time.

Alternative simpler approach:

BCS = clamp( abs(UpperSlope - LowerSlope) / slopeNormalization, 0, 1 )

Weighted higher if:

Slopes opposite sign

WidthSlope negative

5️⃣ Directional Pressure Score (DPS)

Count touches near upper and lower boundaries.

Define epsilon:

epsilon = ATR * touchFactor

Count:

upperTouches

lowerTouches

Compute imbalance:

pressure = (upperTouches - lowerTouches) / totalTouches

Bias:

if pressure > threshold → "up"
if pressure < -threshold → "down"
else → "neutral"

PressureStrength:

DPS = abs(pressure)
Compression Score Composition

Multiplicative core (structural tension must be coherent):

core =
    pow(WCS, w1) *
    pow(VCS, w2) *
    pow(BCS, w3)

Then apply pressure influence:

CompressionScore = core * (0.5 + 0.5 * DPS)

Ensures:

No pressure → moderate score

Clear pressure → amplified score

Edge Case Handling
Case 1: Tiny Range + Sudden Spike

Problem:
Looks structurally clean but useless.

Solution:

Add Minimum Range Filter:

rangePercent = (maxPrice - minPrice) / meanPrice

If:

rangePercent < minStructuralRange

Then:

CompressionScore *= smallRangePenalty

Prevents micro-noise compression.

Case 2: Event Spike + Recovery

If:

Width temporarily expands

But structure reforms within lookback window

We avoid hard rejection.

Instead:

Use rolling regression window, not full-range.

Optional:

Penalize extreme candle deviations using z-score

But allow recovery if post-spike contraction resumes

This prevents over-penalizing healthy recovery.

Output Structure
type CompressionResult struct {
    Score float64
    Bias  string // "up", "down", "neutral"

    WidthContractionScore float64
    VolatilityContractionScore float64
    BoundaryConvergenceScore float64
    DirectionalPressureScore float64

    ChannelWidthSlope float64
    ATRSlope          float64
}
Configurable Parameters

All in single config struct:

type CompressionConfig struct {
    SwingLookback int
    ATRPeriod int

    MinStructuralRange float64

    WidthWeight float64
    VolWeight float64
    ConvergenceWeight float64

    TouchFactor float64
    PressureThreshold float64
}

No hardcoded magic numbers.

Interaction with Other Engines
Regime	Behavior
Sideways	May overlap but width contraction differentiates
Trend	Usually low compression unless forming flag
Breakout	Compression high before breakout
Post-breakout	Compression drops

No forced exclusivity.

Acceptance Criteria

CompressionScore normalized [0,1]

Bias properly computed

No dependency on sideways

Edge cases handled (tiny range, spike recovery)

No performance degradation > 10%
