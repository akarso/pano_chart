PR-030 — SidewaysV3 (ChannelStructureScore)
Summary

Introduce a new sideways detection algorithm:

SidewaysV3ScoreCalculator


This algorithm models explicit channel structure instead of volatility heuristics.

It detects:

Robust containment inside an envelope

Medium (tradable) channel height

Balanced boundary interaction

Low drift relative to channel height

This replaces heuristic-based sideways detection with geometric structure modeling.

The algorithm will be selectable via:

sidewaysAlgo=v3

Design Goals

Ignore single outlier spikes

Prefer medium channels (not tight noise, not wide volatility)

Require containment

Require boundary balance

Penalize disguised trend drift

Work with 30–60 candles

Fully deterministic

No arbitrary magic weights

Final score range: [0, 1]

Algorithm Overview
S = containment
    × rangeScore
    × balanceScore
    × driftPenalty


Multiplicative structure ensures structural integrity.

If any structural property fails → score collapses.

Data Requirements

Minimum candles: 20
Recommended: 40–60

Input:

[]Candle


Where Candle contains:

Open
High
Low
Close
Timestamp


All calculations use Close unless specified.

Step 1 — Robust Envelope (Outlier Resistant)

Instead of max/min, use trimmed percentiles.

Implementation

Extract arrays:

highs []float64
lows  []float64


Compute:

upper = Percentile(highs, 95)
lower = Percentile(lows, 5)


Channel height:

H = upper - lower


Guard:

if H <= 0 → return 0

Step 2 — Containment Score

Definition:

containment = (# closes within [lower, upper]) / N


Implementation:

inside := 0
for _, c := range candles {
    if c.Close >= lower && c.Close <= upper {
        inside++
    }
}

containment = float64(inside) / float64(N)


Optional hard gate:

if containment < 0.75 {
    return 0
}

Step 3 — Medium Range Preference (RangeScore)

We want medium channels.

Compute relative height:

meanPrice = average(close)
R = H / meanPrice


Timeframe-dependent thresholds.

Configuration

Add struct:

type SidewaysV3Config struct {
    RMin float64
    RMax float64
}


Example defaults:

Timeframe	RMin	RMax
5m	0.003	0.03
15m	0.005	0.05
1h	0.008	0.06

RangeScore calculation:

mid := (RMin + RMax) / 2

if R <= RMin || R >= RMax {
    rangeScore = 0
} else {
    rangeScore = 1 - math.Abs(R-mid)/(RMax-RMin)
}


Clamp to [0,1].

Step 4 — Boundary Balance Score

Detect interaction with channel edges.

Define epsilon:

epsilon = 0.05 * H


Count touches:

upperTouches := 0
lowerTouches := 0

for _, c := range candles {
    if c.Close >= upper - epsilon {
        upperTouches++
    }
    if c.Close <= lower + epsilon {
        lowerTouches++
    }
}


Require both sides touched:

if upperTouches == 0 || lowerTouches == 0 {
    return 0
}


Balance:

totalTouches := upperTouches + lowerTouches
imbalance := math.Abs(float64(upperTouches-lowerTouches)) / float64(totalTouches)
balanceScore := 1 - imbalance


Clamp [0,1].

Step 5 — Drift Penalty

Compute net displacement:

netDrift = |close_last - close_first|
driftRatio = netDrift / H


Penalty:

driftPenalty = 1 - driftRatio


Clamp [0,1].

If driftRatio >= 1 → return 0.

Final Score
score = containment
        * rangeScore
        * balanceScore
        * driftPenalty


Return clamped to [0,1].

Go Implementation Structure

Interface

Assuming existing interface:

type SidewaysCalculator interface {
    Calculate(candles []Candle) float64
}

Implementation
type SidewaysV3ScoreCalculator struct {
    Config SidewaysV3Config
}

func (s *SidewaysV3ScoreCalculator) Calculate(candles []Candle) float64 {
    if len(candles) < 20 {
        return 0
    }

    // Step 1: envelope
    upper, lower := computeTrimmedEnvelope(candles)
    H := upper - lower
    if H <= 0 {
        return 0
    }

    containment := computeContainment(candles, lower, upper)
    if containment < 0.75 {
        return 0
    }

    rangeScore := computeRangeScore(candles, H, s.Config)
    if rangeScore == 0 {
        return 0
    }

    balanceScore := computeBalanceScore(candles, lower, upper, H)
    if balanceScore == 0 {
        return 0
    }

    driftPenalty := computeDriftPenalty(candles, H)
    if driftPenalty == 0 {
        return 0
    }

    score := containment * rangeScore * balanceScore * driftPenalty

    return clamp(score, 0, 1)
}
