# PR-035: Sideways v5 – Structural Equilibrium Detector

## Status
Proposed

## Objective

Replace heuristic sideways scoring with a structural equilibrium detector that:

- Detects tradable range behavior
- Rejects micro-noise
- Detects shock events (ATR spikes)
- Differentiates broken vs recovered structures
- Ensures stable sideways > recovered sideways
- Integrates with MetaScore Engine (PR-033)

This version is the flagship sideways implementation.

---

# 1. Design Philosophy

Sideways is NOT:

- Flat regression
- Low drift only
- High oscillation density

Sideways IS:

- Controlled equilibrium
- Adequate amplitude
- Repeated boundary respect
- Structural continuity
- Tradable range behavior

---

# 2. Structural Dimensions

Sideways v5 produces the following normalized subscores:

1. Channel Coherence Score (CCS)
2. Oscillation Quality Score (OQS)
3. Drift Control Score (DCS)
4. Volatility Optimality Score (VOS)
5. Shock Recovery Modifier (SRM)

Final score is composed via MetaScore HybridStructural mode.

---

# 3. Channel Coherence Score (CCS)

## Purpose
Measure geometric quality of range structure.

## Steps

1. Detect local extrema:
   - Candle high greater than N before and after
   - Candle low lower than N before and after

2. Fit upper regression line through peaks
3. Fit lower regression line through troughs

4. Measure:
   - Parallelness
   - Deviation standard deviation
   - Channel width consistency

## Components

### 3.1 Parallelness

```text
parallelScore = 1 - abs(slopeUpper - slopeLower) / slopeNormalization
3.2 Deviation
Standard deviation of distance from trendlines.

Lower deviation → higher score.

3.3 Width Stability
StdDev(channelWidth) normalized.

Final CCS:

CCS = weighted average of:
- parallelScore
- deviationScore
- widthStabilityScore
Clamped to [0,1].

4. Oscillation Quality Score (OQS)
Purpose
Measure quality of boundary interaction.

We do NOT reward raw number of extrema.

We reward:

Alternating highs and lows

Even spacing in time

Boundary proximity consistency

4.1 Alternation
Penalize sequences of HH-HH or LL-LL without proper reversal.

4.2 Temporal Evenness
Compute stddev of time distance between extrema.

Lower stddev → better.

4.3 Boundary Respect
Measure distance of extrema to regression lines.

Closer → higher score.

Final:

OQS = average(alternation, evenness, boundaryRespect)
5. Drift Control Score (DCS)
Purpose
Ensure equilibrium rather than slow trend.

Use linear regression slope over full window.

normalizedSlope = abs(slope) / channelWidth
DCS = 1 - clamp(normalizedSlope)
Allows small drift.
Penalizes structural bias.

6. Volatility Optimality Score (VOS)
Purpose
Reject micro-flat noise and chaotic expansion.

We compute:

rangePercent = (maxHigh - minLow) / meanPrice
atrRatio = ATR / meanPrice
We apply bell-shaped scoring:

Too small → low score

Medium → highest score

Too large → penalized

Example ranges for 15m:

Range %	Interpretation
< 0.3%	Micro noise
0.5–2%	Ideal
> 5%	Unstable
VOS ∈ [0,1]

This prevents:

Flat garbage

Post-spike compression

7. Shock Detection
7.1 Spike Rule
A candle is a shock if:

candleRange > K × ATR
Recommended:
K = 3.0

7.2 Structural Event Classification
If spike detected:

Segment data into:

Pre-spike

Spike

Post-spike

8. Recovery Evaluation
Compute CCS, OQS, DCS on:

Pre segment

Post segment

Define:

StructurePre  = min(CCS_pre, OQS_pre, DCS_pre)
StructurePost = min(CCS_post, OQS_post, DCS_post)
RecoveryScore = min(StructurePre, StructurePost)
9. Shock Recovery Modifier (SRM)
Cases:

No spike → SRM = 1.0

Spike + strong recovery → SRM ∈ [0.85, 0.95]

Spike + weak recovery → SRM ∈ [0.5, 0.8]

Structural break → SRM ∈ [0.3, 0.5]

Important rule:

Stable sideways (no spike) must always score higher than recovered sideways.

Therefore SRM must never exceed 1.0.

10. Final Composition (HybridStructural)
Recommended composition:

structureCore = pow(CCS, w1) * pow(OQS, w2)
driftAdj      = pow(DCS, w3)
volAdj        = pow(VOS, w4)

baseScore = structureCore * driftAdj * volAdj
finalScore = baseScore * SRM
Suggested default weights (15m):

w1 = 1.3

w2 = 1.2

w3 = 1.0

w4 = 1.0

All configurable via MetaConfig.

11. Timeframe Adaptation
We do NOT change algorithm per timeframe.

We change:

N for extrema detection

CandleCount

Ideal volatility band

ATR multiplier

Weight tuning

Example:

15m:

CandleCount: 110

N: 3

Ideal range: 0.5–2%

5m:

CandleCount: 120

N: 4

Ideal range: 0.7–3%

1m:

Higher ATR tolerance

Lower oscillation strictness

12. Edge Case Handling
Case 1
Tiny range → spike → tiny range

Handled by:

Low VOS

Low RecoveryScore

SRM penalty

Result: low final score.

Case 2
Good sideways → spike → good sideways

Handled by:

Strong pre & post structure

Moderate SRM penalty

Final score slightly below stable sideways

Result: ranked below stable sideways but still high.
