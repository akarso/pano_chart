# PR-020 — Global Top-N Badge System (Single Dominant Signal)

## 🎯 Goal

Replace per-item badge inflation with a **global, competitive badge system**:

- Exactly **one badge per symbol**
- Badges assigned only to **Top-N most statistically notable assets**
- Based on **component percentiles**, not raw scores
- Computed across the **entire universe**, not current page

This transforms badges from classification labels into **anomaly highlights**.

---

## 🧠 Concept

Each symbol has:

- `sidewaysScore`
- `trendScore`
- `gainScore`

And from PR-019:

- `sidewaysPercentile`
- `trendPercentile`
- `gainPercentile`

Now we introduce:

- `maxPercentile = max(sidewaysP, trendP, gainP)`
- `dominantComponent = argmax(sidewaysP, trendP, gainP)`

Then:

1. Sort all symbols by `maxPercentile` (descending)
2. Take **Top N**
3. Only those receive a badge
4. Badge type = dominant component

All other symbols → no badge
