# PR-017 — Detail Screen v2 (Design + Context Upgrade)

## Goal

Upgrade Detail Screen from minimal placeholder to a professional, trustworthy inspection view.

Focus areas:

* Visual polish
* Structural clarity
* Contextual market information
* Transparent score explanation

NOT building TradingView.
NOT adding indicator overload.

---

# Core Problems Identified

Current state:

* Only ~30 candles displayed
* No time context
* No market context (24h stats)
* No explanation of ranking score
* Visually resembles extended sparkline

Result: Feels unfinished and lacks authority.

---

# Design Principles

1. Clean > Complex
2. Explain the algorithm
3. Show structure, not noise
4. Avoid indicator clutter
5. Professional visual spacing and hierarchy

---

# Scope of PR-017

## 1. Fetch More Candles (Detail-Specific)

Detail screen fetches independently from ranking logic.

* 150 candles (default)
* Same timeframe as selected in Overview
* Not reused from sparkline dataset

This provides structural context (~6 days on 1h timeframe).

---

## 2. Add Symbol Header Block

Top section above chart:

* Symbol name
* Rank position
* Ranking mode (e.g. Sideways v2)
* 24h change (%)
* 24h volume

Example layout:

SYMBOL
Rank #3 — Sideways v2
24h Change: +2.3%
24h Volume: $18.4M

Data source: Binance 24hr ticker endpoint.

---

## 3. Chart Visual Upgrade

Improve visual authority:

* Subtle horizontal grid lines
* Right-side price scale
* Consistent candle width
* Improved wick thickness
* Proper vertical padding
* Clear background contrast

No indicators in this PR.

---

## 4. Time Context

Add below header or above chart:

"Showing last 150 × 1h candles (~6 days)"

This anchors the user in time scale.

---

## 5. Score Breakdown Visualization

Display ranking components clearly.

Example:

Sideways  ████████████░░ 0.82
Trend     ██░░░░░░░░░░░ 0.12
Gain      █░░░░░░░░░░░░ 0.04

Implementation:

* Horizontal progress bars
* Numeric value shown
* Minimal styling

Purpose:
Build algorithm transparency and trust.

---

# Explicitly Out of Scope

* RSI / MACD / EMA overlays
* Multi-timeframe switching
* Channel drawing
* User customization options
* Indicator stacking

These belong in later PRs.

---

# Expected Outcome

Detail screen should:

* Look intentional and structured
* Provide actionable context
* Explain ranking clearly
* Feel closer to professional tool than prototype

User reaction target:
"This looks serious and I understand why it ranked."

---

# Acceptance Criteria

* 150 candles rendered cleanly
* Header with 24h stats visible
* Time range label present
* Score breakdown bars implemented
* No layout jitter or overflow
