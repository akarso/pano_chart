# PR-035: Social reply filter + push filtering

## Objective

Add `isReply` field to the social post model with "Reply" badge in the UI,
and `omitReplies` toggle in per-account settings. Additionally, sync
filter settings to the server so push notifications are filtered.

| `lib/features/social/api/social_models.dart` | Add `isReply` field |
