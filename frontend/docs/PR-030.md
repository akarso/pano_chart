# PR-030: Forward Event Projection in Detail View (Future Timeline Extension)

## 1. Objective

Extend the Detail View timeline beyond the last available candle to display **scheduled future events directly on the chart**.

This introduces forward temporal context without predicting price — only visualizing known upcoming catalysts within the same structural framework.

The goal is to:

* Reduce context switching (no external calendar needed)
* Increase perceived intelligence of the tool
* Enhance regime awareness before potential disruption events
* Maintain clean, minimal UX

---

## 2. Scope

This PR introduces:

* Conditional right-side timeline extension
* Rendering of future scheduled events
* Visual distinction between past and future events

No changes to:

* Regime engine
* Indicator calculations
* Candle rendering logic
* Event data source format

---

## 3. Conditional Timeline Extension

### 3.1 Extension Rule

Right-side empty margin is added **only if future events exist in the feed**.

If no future events are present:

* Chart ends at last candle
* No artificial padding

If ≥1 future event exists:

* Extend timeline to cover furthest event timestamp
* Add minimal right padding (fixed percentage or calculated width)

This avoids dynamic padding complexity based on display toggles.

---

## 4. Time Mapping Logic

### 4.1 Horizontal Scale Continuity

Future event positions are calculated using the same time-to-x mapping logic as candles.

* No synthetic candles are created
* Time axis remains linear and continuous
* Empty region visually represents “future time”

### 4.2 Max Projection Window

Limit forward projection to:

* 1 day on hourly timeframe
* 4–6 hours on lower intraday timeframes
* 1–3 days on daily timeframe (if applicable)

Prevent extreme stretching.

---

## 5. Rendering Specification

### 5.1 Visual Treatment

Future events must be visually distinct from past events:

| Element    | Past Event       | Future Event        |
| ---------- | ---------------- | ------------------- |
| Line style | Solid            | Dashed              |
| Opacity    | 100%             | 70–80%              |
| Label      | Standard         | Slightly muted      |
| Icon       | None or standard | Optional clock icon |

Subtle differentiation only.
No aggressive coloring.

---

### 5.2 Empty Future Zone Styling

* No candle rendering
* Gridlines optional but slightly faded
* No price extrapolation
* No artificial projection lines

The space must feel intentional, not broken.

---

## 6. Interaction Behavior

### 6.1 Tap on Future Event

Behavior identical to past events:

* Open event modal
* Show:

  * Title
  * Scheduled time
  * Impact level
  * Countdown (optional enhancement)

### 6.2 Crosshair

Crosshair must:

* Traverse into empty future region
* Display timestamp only (no price)
* Avoid rendering price tooltip in empty zone

---

## 7. Performance Constraints

* Do not rebuild full dataset when extending timeline
* Timeline extension is view-layer only
* No additional candle computations required
* Indicator arrays remain unchanged

---

## 8. Edge Cases

### 8.1 Multiple Future Events

If events are clustered:

* Maintain minimum label spacing
* Prevent overlap via vertical stacking or truncation

### 8.2 No Future Events

* No extension
* Chart behavior unchanged

### 8.3 Extremely Distant Event

If event exceeds max projection window:

* Clamp to projection boundary
* Optionally hide or show indicator that additional events exist

---

## 9. UX Philosophy

This feature:

* Does not predict
* Does not analyze
* Does not signal

It contextualizes.

It reinforces that markets move within structural and macro catalysts.

Forward visibility should feel:

* Calm
* Intentional
* Intelligent

Not dramatic.

---

## 10. Acceptance Criteria

* Future events render only when present
* Timeline extends smoothly without distortion
* No layout shifts when toggling event visibility
* Crosshair behaves correctly in empty zone
* Performance remains smooth (60fps target)
* No visual confusion between past and future markers

---

## 11. Strategic Impact

Forward Event Projection:

* Reduces need for external economic calendar
* Enhances perceived completeness
* Strengthens structural narrative
* Adds screenshot-worthy differentiation

This is a context feature — not a trading signal.

It supports decision clarity without increasing analytical noise.
