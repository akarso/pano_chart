## PR-111: Range planner UI

**Layer:** frontend. **Depends on:** PR-110.

### Scope

- `PlanData` / `HttpPlanApi` for `GET /api/symbol/{symbol}/plan`.
- `PlanPanel`: Long/Short toggle, entry/stop/target, R:R, position bar,
  quality chrome (muted when invalid), risk input (`settings.planAccountRisk`,
  default 100, clamped to `(0.01, 1e7]`), local size recompute.
- Chart: `PlanLevelsPainter` on `InteractiveChart` expands `priceLo`/`priceHi`
  to include Low/Mid/High (+ E/S/T) so lines stay on-screen; ticks/labels sit
  left of the Y-axis gutter. Invalid → no overlay.
- Fetch failure shows retry (not silent absence). Free-tier (`planApi == null`)
  shows neither panel nor error.
- Educational disclaimer copy.

### Out of scope

- Replay mode (PR-112).
- Backend plan changes.

### Tests

- `PlanData.fromJson` + `sizeFor` + `expandPriceRange`.
- HttpPlanApi query path.
- Channel Y geometry on-screen after expand; InteractiveChart mounts /
  omits `plan-levels-overlay`.
- PlanPanel: valid size recompute, invalid reason + muted Q, Long/Short,
  reject risk 0.
- DetailScreen: valid overlay, invalid no overlay, fetch error retry,
  null planApi silent.
