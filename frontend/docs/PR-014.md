# PR-014 — Rankings Integration + Infinite Scroll (Sparkline Unified)

## Goal

Upgrade Overview from static `/api/overview` snapshot to fully paginated, sortable rankings powered by:

```
GET /api/rankings
```

Rankings endpoint MUST now also return sparkline data (fixed precision).

After this PR:

* Infinite scrolling works
* Sort modes work (total, gain, sideways, trend, volume)
* Snapshot consistency is preserved
* Sparkline remains visible for visual validation
* Dominant-signal badge becomes meaningful

This PR turns Overview into a real ranked scanner.

---

# Architectural Direction

We are unifying everything under `/api/rankings`.

Rankings response now includes:

* Pagination metadata
* Scores
* Volume
* Sparkline
* Precision

There will be **one HTTP call per page**.

No hybrid fetching.
No per-symbol candle calls.

---

# 1️⃣ Backend Contract (Updated)

Endpoint:

```
GET /api/rankings?timeframe=1h&sort=trend&page=1&pageSize=30
```

Response:

```json
{

  "sort": "trend",
  "page": 1,
  "pageSize": 30,
  "totalItems": 50,
  "totalPages": 2,
  "precision": 30,
  "results": [
    {
      "symbol": "BTCUSDT",
      "totalScore": 2.75,
      "scores": {
        "sideways": 0.9,
        "trend": 0.85,
        "gainLoss": 1.0
      },
      "volume": 123456.78,
      "sparkline": [42000.0, 42100.0, 41900.0]

  ]

```

Precision is a backend constant (e.g., 30).
Frontend must not hardcode it.

# 5️⃣ Replace GetOverviewImpl

Create:

```
get_rankings_impl.dart
```

Implementation:

```dart
class GetRankingsImpl implements GetOverview {
  final RankingsApi api;

  GetRankingsImpl(this.api);

  @override
  Future<OverviewResult> call({
    required String timeframe,
    required int page,
    required String sort,
    String? snapshot,
  }) async {
    final dto = await api.fetchRankings(
      timeframe: timeframe,
      sort: sort,
      page: page,
      pageSize: 30,
      snapshot: snapshot,
    );

    return OverviewResult(
      items: dto.results.map((e) => OverviewItem(
        symbol: e.symbol,
        sparkline: e.sparkline,
        totalScore: e.totalScore,
        trendScore: e.scores.trend,
        sidewaysScore: e.scores.sideways,
        gainScore: e.scores.gainLoss,
        volume: e.volume,
      )).toList(),
      hasMore: dto.page < dto.totalPages,
      snapshot: null,
    );
  }
}
```

# 8️⃣ Dominant Signal Badge

OverviewItem must include:

* trendScore
* sidewaysScore
* gainScore

Add computed getter:

```dart
enum SignalType { trend, range, move }

SignalType get dominantSignal {
  final maxScore = [trendScore, sidewaysScore, gainScore].reduce(max);
  if (maxScore == trendScore) return SignalType.trend;
  if (maxScore == sidewaysScore) return SignalType.range;
  return SignalType.move;
}
```

UI mapping:

* 🔥 trend
* 🔄 range
* 🚀 move

Keep subtle.
Sparkline remains primary visual signal.
