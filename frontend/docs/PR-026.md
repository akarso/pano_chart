# PR-026: Crosshair & Candle Inspection System for Detail View

## 1. Objective

Introduce an interactive crosshair system to the Detail View chart to enable:

* Precise candle inspection
* OHLC value display
* Volume / RSI / ATR value lookup
* Professional trading interface feel

This feature must enhance precision without adding visual clutter.

Non-goals (v1):

* No drawing tools
* No Fibonacci tools
* No permanent annotations
* No multi-point measuring tool

---

## 2. Activation Behavior

### 2.1 Gesture

* Long press on chart area activates crosshair
* Crosshair follows finger movement
* Release gesture hides crosshair

Optional future:

* Double-tap to lock crosshair

---

## 3. Visual Structure

Crosshair consists of:

1. Vertical line (full chart height)
2. Horizontal line (full chart width)
3. Floating data tooltip box
4. Y-axis price highlight marker
5. X-axis time highlight marker

All elements rendered in Interaction Layer.

---

## 4. Line Rendering

### 4.1 Vertical Line

* 1px width
* Semi-transparent neutral color
* Snaps to nearest candle center

### 4.2 Horizontal Line

* 1px width
* Semi-transparent neutral color
* Reflects exact price level of touch

Lines must not scale thickness with zoom.

---

## 5. Candle Snapping Logic

When activated:

* Determine nearest visible candle index
* Snap vertical line to candle midpoint
* Lock OHLC data to that candle

Horizontal position always represents real touch position.
Vertical value may represent exact price level OR snapped close price (configurable).

Recommended default:

* Snap vertical to candle
* Horizontal tracks exact price

---

## 6. Tooltip Content

Tooltip must display:

* Symbol
* Date / Time (UTC + local)
* Open
* High
* Low
* Close
* Volume

If enabled:

* RSI value
* ATR value
* EMA Fast
* EMA Slow

Example layout:

```
BTCUSDT
03 Mar 2025 14:45 UTC
16:45 Local

O: 63,240
H: 63,820
L: 62,980
C: 63,510
Vol: 18.2K

RSI(14): 62.4
ATR(14): 420
```

Tooltip auto-repositions to avoid screen edge overflow.

---

## 7. Axis Highlight Integration

### 7.1 Y-Axis

When horizontal line active:

* Display price label aligned with Y-axis
* Highlight background behind label

### 7.2 X-Axis

When vertical line active:

* Display time label under candle
* Highlight background

Both must remain readable and stable.

---

## 8. Volume & Oscillator Integration

When crosshair active:

* Volume bar under selected candle subtly highlighted
* RSI / ATR line value at vertical index optionally marked with dot

Do not over-animate.

---

## 9. Performance Constraints

* No full chart rebuild on finger movement
* Only reposition overlay elements
* Value lookup O(1) from visible dataset
* Maintain 60fps tracking

Limit to max 250 visible candles.

---

## 10. Edge Cases

### 10.1 Touch Near Screen Edge

Tooltip must flip left/right or top/bottom automatically.

### 10.2 Zoom During Crosshair

If pinch gesture begins:

* Disable crosshair immediately

### 10.3 Event Badge Overlap

Crosshair must take visual priority.
Event overlay only triggers on tap, not long press.

---

## 11. Optional Enhancements (Future)

* Lock crosshair with tap
* Percentage change from selected candle to current price
* Distance measurement mode
* Multi-chart synchronized crosshair

Not included in v1.

---

## 12. UX Philosophy

Crosshair must:

* Feel precise
* Not feel heavy
* Not interfere with quick browsing
* Activate intentionally (long press only)

It should signal: “This is a serious tool.”

---

## 13. Acceptance Criteria

* Long press activates crosshair
* Vertical line snaps correctly
* Tooltip shows accurate OHLC data
* Axis labels update correctly
* Smooth 60fps tracking
* No layout jitter
* Proper dismissal on release

---

## 14. Strategic Impact

Crosshair elevates the product from:

“Visual screener”

to

“Lightweight trading terminal.”

This increases trust, retention, and perceived sophistication without increasing complexity.

---

END PR-026
