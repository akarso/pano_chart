## PR-085: chore(frontend): glossary enforcement in UI and docs

🎯 Objective

The PR-084 bug was a vocabulary bug (headline vs participation). Make it
impossible to reintroduce deprecated UI words. Authoritative terms live in
`COMMON.md`; a Dart test guards string literals under `lib/features/`.

See ROADMAP Track A — PR-085.

🧱 Scope

- `COMMON.md` — new `## Glossary` section
- `frontend/lib/features/market_state/*` — UI copy + info dialogs
- `frontend/test/vocabulary_test.dart` — ban `prevalence` / `breadth` in literals
- `webpage/help/*.md` — match glossary wording

Out of scope: JSON field renames, backend changes, overview tile copy (already clean).

1️⃣ Glossary in COMMON.md

Copied ROADMAP §1 into `COMMON.md` under `## Glossary`. Deprecated UI words
listed; JSON keys explicitly kept stable.

2️⃣ UI audit

- Market Pulse info dialogs now open with the glossary definition of the card's
  main number (Participation or Regime).
- Transition copy: "compression breadth" → "compression participation".
- Regime subtitle: "same scores as one chart" → "same structure as one chart".
- State / dialog confidence labels use "tape confidence".
- JSON key literals `prevalence` / `breadth` marked `// glossary-ok`.

3️⃣ Vocabulary test

`frontend/test/vocabulary_test.dart` scans `lib/features/**/*.dart` string
literals; fails on whole-word `prevalence` or `breadth` unless the line has
`// glossary-ok`.

4️⃣ Help pages

`Getting_started.md`, `Understanding_scores.md`, `Market_intelligence.md`
updated to participation / glossary wording.

✅ Definition of Done

- [x] vocabulary test passes
- [x] `COMMON.md` has Glossary
- [x] help pages match glossary terms
- [x] every Market Pulse `_showInfoDialog` body begins with a glossary definition
- [x] flutter analyze / flutter test clean for touched surface

🚀 Result

Users see Participation / Tape / Regime / Tape confidence consistently; CI
blocks reintroduction of "breadth" / "prevalence" in feature string literals.

- Method / class names (`_buildBreadthCard`, `MarketBreadth`, `trendBreadth`)
  left alone — not user-visible; vocabulary test only covers string literals.

  both dialogs lead with the **Regime** definition (the concept they explain).
- Market Metrics leads with **Participation** (the glossary term on that card);
  Volatility / Dispersion stay as supporting copy (not in the glossary table).
- Unrelated WIP on `dev` (billing / rate-limit) was not touched.
