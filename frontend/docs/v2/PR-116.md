## PR-116: feat(market-pulse): chart-first layout, one verdict, participation by count

🎯 Objective

Market Pulse showed four structure bars above the composite chart and a
"Token Participation" card that echoed the same mix as the headline. The
bars could only agree with the verdict or expose a bug, and they sat above
the evidence they claimed to describe. This PR makes the chart the evidence
and the headline its caption; the bottom card answers a different question
(count-based up / down / ranging).

See ROADMAP Hotfixes — PR-116. Depends on PR-115 (`windowBars`, `trendScore`,
`participation`).

🧱 Scope

- `frontend/lib/features/market_state/market_pulse_screen.dart` — card order,
  headline without structure bars, participation card, chart painter wiring
- `composite_chart_painter.dart` — scored-window dimming + OLS regression
- `participation_counts.dart` — model + bias-aware reading
- `regime_data.dart` / `market_state_data.dart` — parse PR-115 fields
- Tests; ROADMAP §1 Participation already by-count

Out of scope: backend scoring; renaming JSON `metrics.*Breadth`; Track C;
rewriting COMMON Tape-confidence / PR-115.md (contract PR).

1️⃣ Layout order

`mp-headline` → `mp-composite` → `mp-participation` (only when counts exist)
→ Market Metrics → Transitions → Regime History.

2️⃣ Headline

Structure bars removed from the card; mix lives under "Structure mix" in
`_showRegimeInfo` (`Key('mp-structure-bar-$label')` on those rows only). Subline
uses `min(windowBars, chartLen)` and includes `• {timeframe}` on scored
captions. When the chart is longer than the tape window, copy states the
chart is context (not the scored rebase).

3️⃣ Chart evidence

Fetch `compositeChartLimit` (200) for historical context. Scored dimming /
OLS only when the displayed series matches `regimeSource` **and**
`chartLen ≤ windowBars` (same first-close rebase as `CalculateTape`). A
200-bar chart with a 110-bar tape is context-only — no false scored suffix.
Chip choice survives refresh. Card `%` follows the scored window when
aligned, else the full context series.

4️⃣ Market participation

Replaces "Token Participation". Stacked bar + reading that checks headline
`bias` / `regime` before saying "with the tape". Metrics rows renamed to
"Avg … mix" so the glossary word stays on the count card only.

✅ Definition of Done

- [x] Widget order keys when participation has data
- [x] Headline has no structure bars; mix only in info dialog
- [x] Caption honest for short charts and long context charts; fallback tested
- [x] Bias disagreement → "against the tape"
- [x] Safe participation parse; empty card not mounted
- [x] Painter recorded-draw coverage: fill-under-stroke, dim prefix, clipped OLS, flat series
- [x] `vocabulary_test` still passes
- [ ] Before/after screenshots of the same live 4h payload — paste after deploy
  (layout is covered by widget tests; live payload shots need a running backend)

🚀 Result

Headline captions the scored tape; a longer composite is explicit context;
participation can disagree with the tape without claiming agreement.
