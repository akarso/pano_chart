## PR-079: fix(frontend): upgrade to Google Play Billing Library 8.0.0

🎯 Objective

Google Play requires all apps to use Google Play Billing Library 8.0.0+ starting 2026-08-31,
or updates will be rejected. The app currently pulls in Billing Library 7.1.1 transitively via
`in_app_purchase_android`.

🧱 Scope

Frontend only (Dart/Flutter):
- `pubspec.yaml` — bump `in_app_purchase`
- `lib/features/billing/billing_manager.dart`
- `lib/features/billing/upgrade_screen.dart`

1️⃣ Dependency bump
```yaml
# pubspec.yaml — before
in_app_purchase: ^3.2.0

# after
in_app_purchase: ^3.3.0
```
Pulls `in_app_purchase_android` from `0.4.0+5` (Billing Library 7.1.1) to `≥0.5.0`
(Billing Library 8.0.0).

```bash
cd frontend && flutter pub upgrade in_app_purchase in_app_purchase_android
```

2️⃣ API compat check
Review `billing_manager.dart` and `upgrade_screen.dart` for breaking changes in
`in_app_purchase_android` between 0.4.x → 0.5.x (BillingClient major bump typically touches
`PurchaseDetails` / `BillingResponse` handling).

3️⃣ Verification
- Exercise purchase flow on a testing track (sandbox), not just unit tests.
- Confirm `_verifyAndComplete` server-verification path (see PR-078) still behaves correctly
  against the new client.

🚀 Result

- App ships on Play Billing Library ≥8.0.0, unblocking future Play Store updates past the
  2026-08-31 deadline.
