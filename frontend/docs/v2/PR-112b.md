## PR-112b: feat(replay): frontend scrubber

🎯 Objective

Let Pro users step the Market Pulse and rankings grid back in time using the
backend `?asOf=` contract from PR-112a. See ROADMAP Track F — PR-112b.

**Ship gate:** `kReplayUiEnabled` (default **true** after 112a landed on
`dev`; `--dart-define=REPLAY_UI=false` to hide). Bootstrap only wires
[ReplayController] when enabled.

🧱 Scope

- `ReplayController` + bar-alignment helpers (`replay_asof.dart`)
- Persistent banner + bottom scrubber (`replay_widgets.dart`)
- Overview grid + Market Pulse: Pro toggle, TF-aligned `asOf` on capable
  fetches, auto-refresh paused while active and restarted on exit
- Scorecard chips use absolute `since = asOf − 30d` (best-effort window start;
  **not** full point-in-time without backend `until=asOf`)
- Bootstrap shares one controller when `kReplayUiEnabled`; Overview skips
  reload listeners while Pulse holds `acquirePulseSurface` (menu + notification
  routes); UI notifies immediately, fetch reloads debounce 400ms

Out of scope: Market `/state` and sector-rotation historical replay (cards
hidden while replaying); backend scorecard `until`; free-tier access.

1️⃣ Alignment

One logical UTC instant; each surface calls `asOfFor(timeframe)` /
`asOfUnixFor(timeframe)` so requests and the banner match that TF's bar
grid. Overview TF changes always reload even when the aligned unix is
unchanged.

2️⃣ Surfaces

- Overview nav history icon (Pro) → banner above the grid, scrubber below
- Market Pulse AppBar history icon → same banner/scrubber; opens with the
  Overview timeframe when pushed from the menu
- Exit returns to live fetches and restarts auto-refresh (does not wait on
  a successful reload)
- Live-only Pulse cards (state / participation / sectors) are hidden in
  replay; footnote notes MTF overlay is off

3️⃣ Scorecards

`ScorecardCatalog.load(since:)` accepts absolute RFC3339 under replay.
Chips are a **window-start** hint only until `until=asOf` exists.

4️⃣ Cache

Rankings offline cache is not written or read while `asOfUnix != null`.

✅ Definition of Done

- [x] Scrubber steps emit bar-aligned `asOf` for the active TF
- [x] Auto-refresh paused in replay; exit restarts without requiring a
      successful fetch
- [x] Pulse main load generation-guarded against scrub races
- [x] Overview TF change under replay always reloads
- [x] flutter analyze clean for touched packages
- [x] Backend PR-112a gated behind `kReplayUiEnabled` (default on after merge)

🚀 Result

Pro users can scrub historical rankings and Market Pulse with a clear
"Replay: … UTC" banner and Exit.
