## PR-038 adding gates to pro version

- I need to add gates, so that after trial expiration users which chose not to get subscription get free version instead

- this has to be done in such a way, that one centralized setting enables or disables all the features required. Of course, this must be checked in the database. We have google billing library, but we should also have some status table on backend with 'status' and 'expiry_date' or something. Subscription will be 4.99 EUR monthly or 49.9 yearly.

- free version:
    - first 10 tokens, no 'hi res' setting
    - no auto refresh
    - sorting by gainers, losers, volume
    - detail view - candles, rsi, atr, ema clouds, volume, no 'future x axis'
    - macro events - only in the events tab, 3 future and 3 past ones
    - bubble maps - volume only
    - F&G index
    - push notifications settings page with only 'news' section

- pro version:
    - generally everything in app available, so:
        - ~150 tokens, all settings and sorting
        - auto refresh
        - detail view with 'future x axis'
        - macro events - 2 days ahead, one day back
        - retail behavior engine
        - market pulse page
        - token diagnostics (setup quality, crowding, state age)
        - social feed
        - push notifications with settings page

- we will have probably once again revisit backend flow, to send all push messages only to pro and trial users and to free users only news ones

- I don't want 'hinting at pro version' everywhere, users should be able to find the link 'get pro' in menu. To be sure - make this link green color, once trial is gone, but subscription not active. Anyway - just hide features, do not make them 'unactive', unless this would be impossible.
